# ADR-0145: Admit declared execution and compose scientific qualification

## Context

Plan 25e replaces caller-specific route/default interpretation and success predicates. ADR-0106 and ADR-0111 describe the predecessor policy; their immutable arguments remain available while this supplement follows the decision-PR route.

## Scope

Amend the declared-execution, structural admission, lexicographic selection, qualification, trajectory and Python boundary contracts in the cited architecture owners. Implement E1–E5 and only their required F/G/I/J prerequisites. This record does not accept broader companion plans or series qualification.

## Drivers

Authored choices must survive inspection and execution. Adapter representation must not change Root meaning. Result permission must preserve independent evidence, including combined opt-ins. Native work must retain resource ownership until destruction completes.

## Options

Retaining combined execution tags or reconstructing defaults in Python creates multiple authorities. A universal success enum conflates native stop with scientific permission. Inserting terminal events into the requested grid changes observation meaning. Select distinct route/procedure admission, composed typed reasons and a separate actual endpoint, reusing existing matching, supervisors, integrators and solver evidence.

## Outcome

Rust admits authored route and procedure independently, resolves omitted defaults once and preserves requested/applied starts. Contradictory overrides refuse. All authored-case consumers retain the admitted procedure; raw unadmitted shooting becomes internal and supervised asynchronous execution owns cancellation, resources and destruction.

Assess complete original Root equations with square matching across every representation. Optimization nonlinear representations require equality matching; justified affine/conic native-feasibility policies remain explicit capabilities. Preserve scope, identities and refusal evidence. Native lexicographic execution requires capability and compatible authored degradation; otherwise stage on an admitted backend. Partial incumbents cannot establish completion of an earlier priority.

Compose native termination, original candidate qualification, model checks, closure, applicability and coverage independently. Default incumbent Refuse may retain a lawful seed. AcceptFeasible admits only independently validated original-feasible candidates at supported time/node/iteration/solution limits. AcceptWithinGap additionally requires a valid original-objective bound and the owner-defined authored gap criterion. Failure, cancellation, relaxed-only or diagnostic points cannot be upgraded. Missing required closure refuses even under AllowUnclosed; completed outside-tolerance closure can be explicitly allowed with residuals retained. Preserve every applicable qualifier and refusal as typed facts.

FixedHorizon is the endpoint default. DeclaredTerminalEvent admits only the named terminal event without resets. Publish actual root state, mode, quadratures and live inputs before termination or coincident scheduled changes; evaluate endpoint-relative obligations there. Fixed-domain integrals and later required downstream observations retain their original extent. Qualified prefixes, coverage and final permission remain separate.

### Consequences

Delete replaced combined fixture fields, copied defaults, local success predicates and bypass entrypoints. Generate transport from declarations. Version changed identity frames and durable contracts; absence in historical records cannot become current evidence.

### Compensating controls

Focused force-validation matrices cover representation admission, route/procedure agreement, defaults, incumbent stops/bounds, combined policies, missing closure, terminal input sides and supervised shooting. Capacity accounting includes actual endpoints. Native priority advancement remains conservative when optimality is unestablished.

### Confirmation

The bounded author review establishes proposed contract fitness only. Plan 25e owns executed focused evidence; integrated qualification remains Plan 25k. This ADR remains proposed until its governed decision PR.
