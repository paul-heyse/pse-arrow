# ADR-0265: Admit source-bound exact analytical and assurance products

## Context

D/E introduce useful exact blocks, precision-scoped diagnostics, analytical/indexed products and typed selected observations over the existing admitted source. Current f64 products and solver certificates retain different meanings.

## Scope

Amend blueprint §14.3.4 within library-owned mathematics. The compiler owns selected source, physical axes and obligations; Symbolica/Numerica/Graphica own algebra, arithmetic and canonicalization. Stored result views grant no authoring or proof authority.

## Drivers

Keep exact identity, chosen precision, propagated error and validated enclosure distinct. Reuse selected definitions and sparse evidence rather than flatten every model or add an application CAS.

## Options

Select request-owned exact views and controlled native operations. Ordinary f64 mapping and printed text cannot establish certification; a second elimination or interval interpreter duplicates library authority.

## Outcome

### Consequences

Admit source-bound analysis and observation variants with original physical/source/guard/provider premises. Generic rank carries sufficient pivot/denominator exclusions and exceptional values re-evaluate original rows. Validated balls admit rational basic arithmetic and integer powers only. Precision callbacks must meet the actual requested realization; unsupported claims refuse. Native derivative/series/indexed/printer products remain separate from physical feasibility and execution interchangeability.

### Compensating controls

Use existing captured operation scope and allocation owners, before-growth supplier control and maintained provenance. Preserve sparse affine proof, LDLᵀ/Gram, root containment and ordinary numerical policy. Analytical logarithm projection preserves original guards and does not alter stable numerical heads.

### Confirmation

D01–D06 and E01–E05 own independent exact-block, rounding/enclosure, caloric/indexed and protected old-result acceptance; no implementation or test is claimed by this initial record.

## Pros and cons

Native composition consolidates mathematical and execution authority, while requiring explicit domain, control and persisted-result contracts. These obligations are implemented with the capability, not deferred to a reader or a library name.
