# ADR-0218: Compose scientific research through admitted sources and original fit evidence

## Context

Plan51a/51b provide project, source, temporal and evidence-storage foundations. The maintainer authorized the complete 51C extension through existing owners.

## Scope

New owned declarations and composed consumers under blueprint [§19.3, §19.4, §20.6]; this amends their target within existing architectural decisions. No backend, numerical solver, host authority or Python-boundary replacement is selected.

## Drivers

Preserve scientific/source meanings and truthful evidence while making the research and development workflows usable from Rust, Python and CLI. Keep metadata selection short and selected payload work explicit.

## Options

Compose existing admission, result, query and host readers rather than a second measurement model, global history wrapper, source scanner or competing store. Native indexed selections locate compact facts; selected columnar processing performs aggregates. This keeps changed behavior at its actual owners and admits bounded representative tests without a new general framework.

## Outcome

Immutable dataset versions organize existing admitted measurement/data objects and their physical/provenance context. Calibration uses existing typed authored derivations or quantity conversion and explicitly authored transformed standard uncertainty. Missing unsupported uncertainty cannot become an included weighted observation.

Fit publication selects qualified cells from one original sealed run/attempt. Retain original export eligibility at the result owner; reopening must not reconstruct qualification from generic run status. Explicit target mappings produce ordinary admitted source deltas, with exact source CAS, ancestry and publication receipt in one source-owner activation. Covariance qualification remains independent of eligible point estimates.

Frozen bounded cohorts preserve exact membership and missing outcomes before selected protected result analysis. Read-only study observers compose actual per-attempt sequences, checkpoints and terminal history, report gaps, and never cancel or advance science. External acquisition is not adopted; explicit authored/file/batch admission is supported until a named producer has defined clock, calibration, ordering and loss semantics.

### Consequences

Declarations generate storage and public contracts. New consumers carry exact identities, coverage and ownership; missing supported evidence receives an explicit refusal or unavailable result.

### Compensating controls

Original immutable intents, issuing-authority checks, short guarded transactions, bounded selection and protected detail reads preserve existing failure and lifetime semantics.

### Confirmation

Tested: research_calibrated_fit_reopens_and_publishes_original_cells, public cohort/observer controls and Python research/workbench journeys on Linux with the pinned MX1.0 service and force-validated correctness builds; assembled qualification remains Plan51g.

Implemented and targeted-tested through admitted Parquet/measurement sources, actual calibrated residual LM, original eligible fit export, local preview/guarded publication and downstream prediction. Native snapshot cohorts and passive observation use original protected results/progress; public Python and typed CLI consumers are exercised. The owning plan records exact commands, corrected failures and support limits. No assembled qualification or performance measurement is claimed.

## Pros and cons

Reuses established scientific and operational ownership; requires explicit version/cut, eligibility and association metadata rather than convenient inferred links.
