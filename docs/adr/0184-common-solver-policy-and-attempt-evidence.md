# ADR-0184: Govern solver choices with shared policy and truthful attempt evidence

## Context

Plan38's accepted S-RC01–04 and S-RC08–11/13 require one effective preference/transition meaning and truthful consumed observations. Contextual native admission, the pure runtime walker, original assessment, finite aggregate budgets and nonblocking optional progress already exist; current preference interpretation remains dispersed. Plan38b now has implementation authorization, including minimum C1/C3 native-fact and D2 raw-map producer slices and bounded optional advice.

## Scope

Amend the governing policy, observation and replay clauses of ADR-0152/0154/0158 and the generated Python boundary. Keep their unrelated numerical, scientific and lifecycle contracts. No new crate, native method, session-reuse topology, publication protocol or per-event journal is selected. Accepted ADR statuses remain unchanged; this record stays proposed pending its decision PR.

## Drivers

The same physically meaningful request must govern ordinary solves, initialization, recycles, fitting, dynamics and extension with another adapter. Pure policy must be testable with its actual dependencies; unavailable or lossy telemetry must not change science. New values require original assessment; an auxiliary stationary point or a native success status cannot grant a different scientific result.

## Options

Keeping selectors independent retains contradictory policy and repeated interpretation. Placing scientific branch/start/transition meaning in native routing avoids a dependency cycle but mixes it with adapter integration. Select small pure functions alongside the existing model strategy contracts, consumed by native routing and the existing runtime walker. Keep class-specific builders and library-owned algorithms rather than adding a universal instruction language or second planner.

## Outcome

`pse-model::strategy` owns governing preference/permission/transition operations over injected contextual facts and typed cause projections. Adapters own actual scientific/profile support, settings and preparation requirements. The runtime walker owns effects, error payloads, original assessment, retained proposals and one aggregate deadline/work ledger. Scientific controllers retain maps, physical coordinates and acceptance. Explicit backend/profile/options and declared order are constraints; baseline Auto preferences remain complete without advice. Pending evidence is distinct from refusal and missing prepared products.

Cancellation/deadline, invalid contracts, panic, infrastructure and resource failure veto successors. A policy stop is local to an attempt and may expose a screened proposal, never success by status. Native stop fidelity is profile-specific; unavailable mid-attempt control waits only for its supported boundary. Proposal transforms are explicit and original-domain/branch/physical checks run before use. Missing/incomparable merit retains baseline order; objective alone cannot establish physical superiority.

One compact bounded typed attempt product extends current WorkEvidence/reports/trace, retaining requested/effective choices, reasons, available method-specific counters, original conclusion, start/reuse provenance and actual interval meanings. Synchronous decision observations do not depend on queued progress. Existing ordinary durable progress remains bounded, nonblocking and separately loss-accounted. Optional writer failure does not replace science; required terminal recording remains fail-closed under its original effect identity.

D2's early producer records actual map evaluations and raw G(x)-x, physical Err/Tol, known sample role, failure and last-successful state. Accelerated step norm and native iteration totals cannot substitute for raw history. Unknown sample roles stay unknown. Library iteration, acceleration and restart defaults remain unchanged.

Automatic failure summaries use retained final/best accepted evidence only. Richer diagnosis is explicitly admitted; a hard stop never triggers hidden model/native work. Preserve the existing 25-kind model catalog and automatic boundary diagnostics.

Replay has explicit input reconstruction, recorded-decision replay and tolerant numerical rerun levels. Native continuation requires an actual library-owned checkpoint; a point is not one. Export the immutable input/provider/physical/mapping/build closure and actual effective policy/advice/settings/starts/limits. Missing required premises refuse. A new rerun has new execution identity and allowance; existing occurrence recovery cannot reset its clocks or unsettled effects.

Advice is opt-in and frozen before execution and through study recovery. It can reorder only permitted equivalent Auto candidates using explicit comparable cohorts/metrics and complete matched observations. Partial/censored/unmatched comparisons retain baseline ties and their distinct outcome counts; no inferred zero observations. Automatic numeric tuning is not selected. Any supplied tuning is re-admitted, materialized and bounded by original permissions/limits. No mutable-history lookup is required during execution or replay.

### Consequences

Migrate current routing, runtime Auto, initialization/block, presolve, recycle, fitting/shooting, dynamics and offered linear-profile consumers; remove replaced decision trees after revealing controls pass. Actual native option and library-internal Auto meaning stays with its adapter. Native methods, state reset/reuse, broader scientific controllers and storage/analytics remain separately owned.

### Compensating controls

Keep original root/LS/VI/global and branch/start/accuracy permissions distinct, count failed/nested work once, keep unknown counters absent, bound records/queues and retain allocation owners through drain. No candidate is a usable result without fresh original scientific acceptance. Optional advice cannot repair missing contextual eligibility or native-state evidence.

### Confirmation

Interface-checked target grounded in the audit and current source. The independent bounded target review accepted this amendment before dependent product changes; actual targeted implementation evidence belongs to Plan38b and assembled scientific/native/durable acceptance to Plan38g. No speed, memory, whole-product or ADR-acceptance claim follows.

## Pros and cons

One shared meaning improves change locality and makes policy independently testable. The migration must preserve distinct scientific controllers, actual profile facts and original failure/lifetime contracts; a common result schema alone is insufficient.
