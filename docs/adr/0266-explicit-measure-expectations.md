# ADR-0266: Execute explicit-measure expectations through original study members

## Context

F adds scientific measure and estimator meaning to existing study/source/member execution. DOE seeds and covariance are not probability laws, and immutable finite Study definitions cannot become appendable adaptive populations.

## Scope

Amend blueprint §19.3.1 within existing native workflows. A versioned expectation parent composes finite original child studies and typed case-solve or selected-observation members; no second worker service is introduced.

Actual registered sample rows cross the native boundary with their source-owned result-selection
roles and sort ordinals. Publish those existing meanings as typed registry field options, using
the same closed role vocabulary and ordinal parser as the relation owner. Preserve their
agreement with the original native field carrier. These annotations describe selection keys
and ordering; they do not grant access to a result or replace run/attempt/manifest protection.
Value-admission and identity policies for the facets remain unchanged.

## Drivers

Preserve declared probability, physical outputs, member failures, affine representation and original recovery. Reuse library grids/statistics and protected original results instead of local VEGAS/statistical loops.

## Options

Select explicit unit-cube/category target law, optional authored joint pushforward and separate fixed/adaptive realizations. Dropping failed members, self-normalizing proposal weights, adapting lanes independently or recovering from a seed would change scientific meaning.

## Outcome

### Consequences

Fixed sampling draws the target and averages each output once. Adaptive contributions are p(c)*(f-b)*w with b restored after averaging; training uses the uncorrected dimensionless target and library proposal weighting. Missing required positive-weight outputs withhold completion. Statistical errors are estimates, not enclosures. Typed selected-observation members use admitted actual output expressions, never reinterpreted residual rows or batched solver state.

### Compensating controls

Freeze proposal per iteration; merge compatible lanes exactly once before one update. Seal source-bound grid/accumulator/RNG/child state only after original child settlement. Resume that boundary or a distinct attempt, never a half-applied merge. Keep zero-mass categories and all original outcomes in attribution; operational loss is not physical failure.

### Confirmation

F01–F05 own independent heater1050/875W, affine reference, failed-member, proposal normalization, nested clone, exact child recovery and protected independent reader journeys. No implementation or test is claimed initially.

## Pros and cons

Native composition consolidates mathematical and execution authority, while requiring explicit domain, control and persisted-result contracts. These obligations are implemented with the capability, not deferred to a reader or a library name.
