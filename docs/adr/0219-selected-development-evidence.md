# ADR-0219: Query selected development evidence without transferring source authority

## Context

Plan51a/51b provide project, source, temporal and evidence-storage foundations. The maintainer authorized the complete 51D extension through existing owners.

## Scope

New owned declarations and composed consumers under blueprint [§24.1, §23.1]; this amends their target within existing architectural decisions. No backend, numerical solver, host authority or Python-boundary replacement is selected.

## Drivers

Preserve scientific/source meanings and truthful evidence while making the research and development workflows usable from Rust, Python and CLI. Keep metadata selection short and selected payload work explicit.

## Options

Compose existing admission, result, query and host readers rather than a second measurement model, global history wrapper, source scanner or competing store. Native indexed selections locate compact facts; selected columnar processing performs aggregates. This keeps changed behavior at its actual owners and admits bounded representative tests without a new general framework.

## Outcome

Host owners export explicit authentic snapshots with source codec, authority, original identity, digest/cut, coverage and declared links. Extend the existing compact evidence family for contexts, associations and measurement populations; no log guessing or duplicate source authority.

A supplied-only native Arrow/DataFusion query path is independent of deployment configuration, scientific runtime, extension and test execution. Explicitly selected evidence cuts preserve one source snapshot per population; history comparison is separate. Reuse these semantics over the existing isolated staged/activated tooling index. Imported presence grants neither freshness nor raw-artifact custody.

Diagnostic tool, target execution and scientific outcomes remain distinct. Detail goes through original owner protection or validated supplied copies. Performance cohorts preserve actual context, censoring and sample membership; unknown Criterion-to-invocation association remains unavailable. No automatic regression/causality or speed benefit is claimed.

### Consequences

Declarations generate storage and public contracts. New consumers carry exact identities, coverage and ownership; missing supported evidence receives an explicit refusal or unavailable result.

### Compensating controls

Original immutable intents, issuing-authority checks, short guarded transactions, bounded selection and protected detail reads preserve existing failure and lifetime semantics.

### Confirmation

Tested: native evidence query/generation controls, 48 host adapter/lifecycle controls and three actual supplied-only executable controls on Linux with force-validated native queries; assembled qualification remains Plan51g.

Implemented and targeted-tested through authentic owner adapters, actual supplied-only native queries with unavailable service/product context, explicit persistent generations/cuts, declared diagnostic associations and selected released/copied detail. Measurement controls retain genuine samples, censoring, actual/unknown context and unsupported membership. The owning plan records exact commands, corrected failures and support limits. No assembled qualification or performance measurement is claimed.

## Pros and cons

Reuses established scientific and operational ownership; requires explicit version/cut, eligibility and association metadata rather than convenient inferred links.
