# Library capability reference

These maps describe pinned library APIs and their scoped evidence. Choose the relevant map
from this collection; run `just lib-outline <file>` before reading its large body. The library
skills supply task routes and exact-release context where available.

[Arrow](arrow-rust.md) and [DataFusion](datafusion_data_model_contracts_capability_spec.md) cover the columnar/query foundation.
Read the selected capability and its evidence, then inspect the intended consumer's contract.
Library capability is not proof of product integration, and old measurements keep their original
conditions. The [dependency policy](../dev/dependency-policy.md) governs admission.
