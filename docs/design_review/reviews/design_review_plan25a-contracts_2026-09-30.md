# Plan 25a contract decision review — 2026-09-30

## 1. Scope, drivers and evidence

**Tier:** design. **Purpose:** target. **Standard:** core 3.3 / process-simulator 1.3.
This bounded author review covers proposed ADR-0135/0136 and the maintainer-approved
25a execution design. Its boundary is physical admission, intermediate typing,
mapped scientific interfaces, directed transfers and field-purpose projections.
It does not re-audit the two codebase reviews or qualify an implementation.

Evidence is the existing quantity/modeling/compiler/columnar/relational interfaces and
the source-grounded execution design. No tests or numerical campaign were run for this
review. Proposed decisions precede governed changes; numeric finite-admission repair
enforces an existing contract.

## 2. Contract and responsibility assessment

| Phenomenon | Owner/product | Consumed meaning and refusal |
|---|---|---|
| Numeric representation | Quantity-owned admitted conversion plan | Complete target contract; finite input/output; representation never changes datum/basis |
| Anonymous intermediate | Quantity resolved contract and occurrence admission | Qualified kind algebra, indices and numerical units; no dimension-only named-boundary coercion |
| Reduced scientific coordinates | Modeling map/slot and checked function application | Exact role/reference dependencies; no Scalar cast or independent runtime interpreter |
| Physical potential | Authored reconstruction contract over admitted law application | Residual versus total and excess normalization retained; existing Symbolica partials |
| Directed energy transfer | Specialized boundary wrapper and explicit reorientation/exchange | Owner and convention preserved; one contribution sign; material datum separate |
| Reference translation | Authored source/target anchors and composition | Scientific evidence and context, never an implicit unit or heat conversion |
| Field comparison | Schema declarations generated to columnar | Purpose-specific equivalence and distinct directional admission; unknown metadata retained |
| Relational physical compatibility | Selected checked rows projected through quantity admission | Same unit algebra, no upper-runtime dependency or global fallback |

Neutral coefficients, library mathematics, exact rational arithmetic, Arrow traversal and
native relational operations retain their roles. The target adds missing meanings rather
than a second generic engine.

## 3. Change scenarios and alternatives

S01/S09 from the original review remain the scenario owners. Adding a lawful map or
reference-dependent potential changes authored declarations and invokes generic checking;
wrong role, basis or datum refuses. A noncanonical defined unit follows quantity admission
instead of adding a SQL unit resolver. A new metadata facet changes its schema declaration,
not several consumer lists. Focused contracts can be exercised without native solver/store
startup.

Dimension-only intermediates, public kinds for every intermediate, a map interpreter,
one universal field equality and independent SQL unit algebra were rejected. Their
concrete losses are captured in the two decision records.

## 5. Behavioral and scientific assessment

G1/G2/G3/G6 and PS-G1/PS-G3 have explicit target invariants and discriminating focused
controls: canonical conversion, qualified algebra, context identity, map derivatives,
reference changes and signs. G4/G5/G7/G8 retain existing numerical/library/lifecycle
mechanisms; changed interface claims remain bounded to the supplied contracts. PS-G2
solver well-posedness is outside this boundary; no new solve route is claimed.

Design reasoning does not establish runtime behavior. Targeted evidence is still required
per packet; broader coupled scenarios and numerical qualification belong to 25k. Existing
seed/conformance results are historical, not reclassified as this implementation's evidence.

## 6. Corrections incorporated before implementation

- Reduced potentials are residual/excess quantities, not stored internal energy or total
  Helmholtz energy. Keep the ideal pressure and fugacity terms and avoid double amount scaling.
- Reconstruction consumes an admitted law application, never an arbitrary Scalar authorized
  solely by the expected result dimension.
- Anonymous normalization cannot rescue a registered invariant refusal or erase qualified
  factors/free binders; composed canonical scales require explicit normalization.
- Directed transfer ownership remains in modeling, with explicit paired endpoints; it is
  not a proliferation of global equipment quantity kinds.
- Canonical already-admitted numeric values preserve their bits, including signed zero;
  representation conversions retain their existing multiply-then-add behavior.
- The shared physical decoder moves downward; generated facet policy creates no reverse
  schema dependency. The historical catalog comparator already removed is not a deletion task.

## 7. Decision and follow-up

**Decision: Accept-scoped**, at **Proposed** level for ADR-0135/0136 and this implementation
boundary. Architectural fitness is accepted for the specified target. Behavioral adequacy is
specified but unqualified until its actual tests execute; no whole-system verdict is implied.

No additional finding is introduced. Plan 25a owns functional progress and evidence; the
Plan 25 coordinator owns the original/follow-up dispositions. ADR acceptance, when processed
through its decision route, does not close those findings. The implementation must report
any contradiction in this design and resolve it explicitly rather than add a legacy path.
