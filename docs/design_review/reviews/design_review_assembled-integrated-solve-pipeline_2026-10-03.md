## Coherent domain model and ownership

The model governs behavior. An original prepared problem owns scientific identity, bindings, physical rows/guards, normalization, numerical policy and admitted support. A strategy declares mechanisms, profiles, starts, optionality, finite work and evidence requirements. Admission consults those facts; transition consumes actual observations. A derived family retains reconstruction, bounds, objective/rows/guards, sheet and derivative relationships to that original.

Auxiliary success produces a proposal. It cannot grant original result permission. Permission remains the composition of native evidence and independent original scientific assessment. Artifact retention is a separate decision.

| Owner | Responsibility and hidden decision |
|---|---|
| Scientific workflow/model | Authored specification, statistical target, physical assessment, control application and durable effects |
| Pure strategy model/driver | Declared numerical composition, admission, starts, transitions, work and observation semantics |
| Mathematical producer | Reconstruction, derivative actions, product identities and consumed accuracy evidence |
| Native library | Iteration, globalization, factorization, integration and solver implementation |
| Scoped runtime | Admission, absolute deadline, cancellation, worker lifetime, allocations and result transfer |
| Registry/public projection | One vocabulary and mechanical transport of actual identities and observations |

This is the PS-09 ownership split in ProcessSimulator 1.4. The simulator owns scientific and bounded numerical composition where no library provides its complete consumed contract; libraries continue to own numerical algorithms. Enduring contracts remain with blueprint §14.3, §17.1 and §18.6–§18.7; this review does not create another authority.

## Contracts and material execution behavior

### Starts, typed failure, work and permission

Preparation and dispatch have explicit entry precedence. Optional admission refusal does not consume a started entry; dispatched preparation does. Starts are source-bound proposals. Original bound/domain screening neither silently clamps values nor claims equation feasibility. Connected transport requires actual sheet witnesses; multistart cannot replace connectivity.

Terminal callback, contract, resource, deadline and infrastructure causes stop recovery. A numerical failure permits only a declared successor. A limit without required stagnation evidence does not become recovery permission. Local optional expiry and refinement refusal use scoped producer witnesses; generic resource exhaustion remains terminal.

A started operation that returns an error is charged once. Unknown counters remain unknown, and strict counter requirements refuse unavailable evidence. Inclusive native work, strategy totals and subtotal metrics are not added as separate work. Actual provider/profile observations do not invent a concrete native backend for library-only effects.

Original permission and artifact retention remain distinct. An independently owned response factor, compatible session or structural proof may survive without qualifying an auxiliary/rejected candidate.

### Consumed accuracy and selected-sheet refinement

Declared pre-existing evidence is an admission requirement, not fabricated preparation accuracy. Actual reconstruction/action consumers check their produced evidence against demand product, source, validity, order, positive normalization, class and allowance.

The implemented bounded refinement uses the same cancellation/deadline scope and finite round/proof limits. Normalized inverse information guides numerical controls; conditioning and residual estimates remain estimated. Only the final genuine enclosure check supplies certification.

The IBEX fixed-parameter producer proves a fresh root enclosure, checks it lies inside retained uniqueness before compatible enclosure intersection, preserves guards/First support, and uses an interval inverse bound over the required whole hull. Row/column scaling and row sums use outward interval arithmetic. Action enclosures use the contracted root enclosure. Zero conceptual remainder is justified only by the whole-hull uniform inverse bound.

Uniform selection-chart proof and pointwise numerical evidence have distinct retention. Changed numerical options invalidate numeric keys while compatible structure/proof remains. Reduced-oracle refinement receipts bind to the actual last point/action, source and validity; wrong evidence and pool refusal cannot become optional refusal.

### Scope, native retention and observations

Submission creates the absolute deadline before queueing. Preparation consumers race that same deadline without renewing a shared loader. First binding, later rebinding, derivative/action compilation, assembly, dispatch and join preserve the original attempt scope. A dropped waiter leaves running work and teardown with their completion owner.

The native request holds its CPU permit through dispatch and teardown. Borrowed callbacks do not escape native lifetime. Reports, traces, factors and retained sessions carry allocation owners. Native retention keys include relevant source/layout/coordinates/bounds/settings/data/support/sheet/accuracy dependencies. Fresh accepted-point response factors are distinguished from stale iteration setups.

KINSOL block preconditioning now uses actual complete BTF mappings and FERAL nonsymmetric LU. Original off-block coupling remains in the genuine JVP. Native forcing and refresh retain authority. Changed source drops factors; changed sparse layout refuses replacement. Failed setup cannot apply Jacobi silently. Call subtotals do not replace unavailable complete factorization counts.

Its admission covers live fill, checked cubic historical Markowitz memberships/lazy scratch, native Krylov storage and headers. Common retention supplements native payload-word queries with conservative omitted headers and Anderson QR/history arrays. Anderson peak storage is checked before SUN allocations against a finite allowance. Declared-root jobs reserve the same foreign allowance supplied to execution. These are bounded allowances, not measurements of allocator capacity.

### K5-F01 — Missing M4 block-factor route and genuine compiler consumption

**Medium; corrected in inspected source with focused Tested evidence.** Plan 25m's M4/F16 target required admitted library block factors. The earlier `Preconditioner` declaration exposed only None/Jacobi, and KINSOL's setup callback extracted reciprocal diagonals. Genuine directional products repaired only part of the target.

Native controls cover all four Krylov variants, two BTF blocks, zero Jacobi diagonal, retained native allocation with source-driven factor rebuild, changed-pattern refusal, exact FERAL singular cause, memory/deadline refusal and truthful subtotals. See Verification.

### K5-F02 — Omitted KINSOL retained headers and Anderson allocation bounds

**High resource/lifecycle correctness; corrected in inspected source with focused Tested evidence.** Native workspace queries count vector payload words while omitting cloned vector headers and some QR/history arrays. Using only those words plus one object allowance could undercharge escaping retained state. Anderson history bounded by dimension alone did not establish an admitted allocation bound.

Pinned SUNDIALS serial `N_VSpace` and SPFGMR space implementations demonstrate the header omission. `KINAllocVectors` supplies the concrete three history-vector arrays, fold/gold clones, QR matrices and scalar/pointer arrays.

Common `native_header_bytes`, `native_krylov_storage` and `anderson_storage` now bound these actual shapes with checked arithmetic. Admission precedes SUN allocation; retention includes omitted allowances alongside library word queries. Fixed internal headers are covered even without AA/Krylov. The 2026-10-04 continuation's branch check found that the general Krylov bound initially ran only through BlockFactor or positive Anderson history. The final constructor checks every Krylov route, including None/Jacobi with zero history; Picard with Anderson uses the combined peak, not an individual subtotal. Declared-root reservation/execution share the finite foreign allowance. Actual AA MGS/ICWY positives, all-four-Krylov pre-callback unknown/zero/under-budget/oversized refusal, exact-peak admission, combined-peak refusal, overflow, retained ownership and affected runtime consumers passed; no allocator-capacity measurement is claimed.
