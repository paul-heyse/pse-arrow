**Outcome sought.** A best-in-class native process simulator: physically typed models authored once; library-owned mathematics, properties, structure and solvers; truthful, diagnosable outcomes; fast edit → re-solve, studies, recycles and dynamics. The user also asked specifically where bespoke code should give way to library functionality, and which library capabilities the design should be using.

**Baseline.** Plan 14 M00–M21 is implemented. Mathematics goes through Symbolica/Numerica with typed guards. Properties come from FeOS PC-SAFT/DIPPR. Structure goes through pounce-presolve, petgraph and rustworkx. Solvers are direct Ipopt C, POUNCE, KINSOL, HiGHS and Clarabel. Dynamics uses Diffsol BDF, and fitting reuses the same NLP lifecycle. Reuse is split between Salsa and a runtime artifact store. The Arrow/DataFusion/Delta layer keeps source admission, results and exact publication.

M22 status: while this review was being written, the M22 packet recorded M22.1–M22.4 as complete, with M22.5 (independent G1–G8 and PS-G1–PS-G3 reviews) and M22.6 (reconciliation) in final review. AGENTS.md was updated at the same time to describe M22 closure. The packet's functional evidence is 1,697 workspace tests, 127 native, 116+18+4 Python and 4 process journeys, all passing. None of these exercises the defects below: no test compiles an authored `^`, runs unlicensed, publishes twice to one base or fits with `start ≠ 0`. That gap is itself evidence for DP-23.

Earlier reviews dated today rate almost every gate *pass* within bounded scopes. The M22 runtime review explicitly left full G8 library leverage to an independent reviewer; this review supplies it and is offered as input to M22.5.

**Supported scope and non-goals.**
- Analysis modes considered: square steady simulation (KINSOL), NLP optimization (Ipopt/POUNCE), LP/MILP/convex QP (HiGHS), conic (Clarabel), ODE/index-1 dynamics (Diffsol), and steady/transient parameter fitting.
- Workloads considered, per the profile's functional target: edit → re-solve, studies, recycles and tears, dynamics, and extension by a unit/property model or solver.
- Target purpose widens the analysis to what the target needs. It does not relax evidence labels.
- Out of scope: other platforms, GPU, distributed execution and global MINLP (Plan 14 non-goals).

**Method and coverage.**
- **Sub-reviews.** Nine sub-reviews read source and pinned library source, one per scope: symbolic math/compilation; native solver adapters; dynamics/fitting/runtime; structure and graphs; incremental reuse; relational engine and rules; catalog/Delta/schema; physical semantics/authoring/Python boundary; build and evidence tooling. Each used the relevant skill: `symbolica-faer-oximo`, `native-solver-libraries`, `rust-graphs`, `salsa`, `rust-reasoning`, `datafusion`, `deltalake` and `datafusion-tracing`.

- **Execution.** No workspace build, test or benchmark was run. The sub-review of scope A ran three standalone Symbolica 3.0.0 probes (default features, release). They cover literal-power equality, registration-order sensitivity, function naming, derivative-expansion size and let-expansion size. Their source was not retained in the repository.
- **Measured evidence.** The only *Measured* input is the tooling sub-review's reading of the existing receipts under `build/plan14`: changed-file sets computed with the repository's own `sources()` function.

- **Examined and clean.** Guard survival through Symbolica simplification. Exactness of the derivative chain, including num-dual through FeOS. `catch_unwind` containment on every C callback. Completeness of each native status map. Independent re-evaluation of primal feasibility against original bounds. Integrity of Delta control-last publication for readers. Metadata preservation through DurableLayout. Pre-validation of pounce-presolve structural results. Exactness of the tear MILP. `WITH RECURSIVE` invariants. **Absence and outcome states.**
- Distinguished:
  - missing versus present-empty input (tracked Salsa lookups)
  - value-invalid versus derivative-ineligible (`sqrt(0)`)
  - rejected / constant / native / unattempted runs
  - cancellation versus step budget in dynamics
  - completed-prefix trajectories
- Collapsed:
  - Every failure class into `Contract(String)`/`CompileMath` (F16).
  - An acceptable-level stop with a KKT point (F05).
  - A best iterate with an estimate in fit results (F06).
  - Resource exhaustion into `Limit` (F05).
  - A retiring flight into user cancellation (F23).
  - A lost publication race into "unresolved" (F14).

**Equivalence promised.**
- Real algebra on the admitted domain (U1).
- Bitwise equivalence with the old evaluator is explicitly not promised. **No determinism class is declared for the new one** (F04).
- Presolve: original-space postsolve with declared tolerances. The tolerance itself is unit-inconsistent (F09).

### Well-posedness statement (PS profile)

- **Variable roles.** Fixed, free and parameter roles are explicit in `CasePlan`. Initial guesses are separate from specifications. Continuation stages may only replace fixed or parameter inputs, but the replaced values are returned as if they were the specification (F15).
- **DOF and structural analysis.** Maximum matching, DM, components and BTF via pounce-presolve run during Salsa preparation. They run again on every native solve (F28). Structurally deficient equality systems are refused before KINSOL, Ipopt and POUNCE. The dynamic algebraic partition is checked with named rows (the M22-scientific F01 repair).
- **Diagnostics.** Offending rows and columns are `SemanticId`s rendered into prose under a code that says "incompatible physical contracts" (F16). The mapping from rows to instances and ports exists in `StructuralAnalysis.contributions` but is not attached. Numerical singularity is distinguished from structural deficiency. Package cycles become strings.

**Relationship structures.**
- `FlowGraph`: units, ports and connections; directed; parallel edges kept. Built only in tests (F01).
- `CaseIncidence`: equation × variable, bipartite.
- BTF blocks: the solve order, a DAG over blocks.
- Package dependencies: a directed graph, including isolates.
- The engine's plan DAG with hash-consing.

These are distinct structures (PS-05 satisfied). No `NodeIndex` is persisted.

**Boundaries.**
- **Python.** One JSON payload with `deny_unknown_fields` for declarations; Arrow C streams through pyo3-arrow for tables; native work under `py.detach`.
- **Vocabulary.** Enum spellings differ in and out (F24), and errors are code plus prose (F16).
- **Delta.** Metadata round-trips through a derived layout descriptor (strength). Contract identity includes prose (F12).
- **FFI.** Pointer and dimension checks plus `catch_unwind` (strength). A Symbolica abort bypasses all of it (F04).

**Strengths that carry weight.** Each of these would break something if removed.

- **Library ownership of generic numerics.**
  - Symbolica/Numerica own arithmetic, simplification and first/second derivatives; faer owns sparse structure; FeOS/num-dual own properties.
  - pounce-presolve owns matching, DM and BTF; Ipopt, POUNCE, KINSOL, HiGHS and Clarabel own iteration, globalization and factorization; Diffsol owns BDF, roots, output quadrature and consistent initialization.
  - There is no own Newton step, line search, factorization or derivative engine. This is the pivot's main achievement and the reason most G8 findings are about *surplus* rather than *reinvention*.
- **Guard survival.** Guarded arguments get their own formal slots, and output-specific effect sets preserve cancelled obligations (Tested: `domain_survives_symbolic_cancellation`, `typed_output_demand_coalesces_calls_and_keeps_canceled_obligations`).
- **FFI containment.** `CallbackState::evaluate` wraps every C callback in `catch_unwind`, publishes outputs all-or-nothing and separates typed Trial from Fatal failures (Tested: `callbacks_publish_transactionally_and_contain_unwinds`).
- **Independent primal-feasibility check** in original coordinates, gating assurance for every backend.
- **Pre-validation of pounce inputs.** `EqualityIncidence::from_probe` silently drops out-of-range entries, and the pre-validation catches this. The exhaustive DM-invariance test (74,963 incidences) backs it.
- **Delta control-last publication.** SetTransaction witnesses, `max_retries(0)` and exact member versions mean readers never observe partial output.
- **Physical type key.** Kind, basis, reference, point/difference and gauge datum make up the key. Without it, PS-01 would collapse to dimension checking.
- **Native state stays out of Salsa.** Absence and membership are tracked, and cancellation is never memoized.

### Considered and kept (reason verified)

- **Units** — `pse-quantity` dimension algebra. `quantity` 0.14 and uom are compile-time and SI-only, while authored units are runtime-defined, use rational exponents and include currency. Add a §F note.
- **Arrow ownership** — `owned_buffer.rs`. arrow `Array::claim` reserves through an infallible `grow`, and admission here must be fallible (reason recorded in M19). Revisit with a custom `arrow_buffer::MemoryPool`.
- **Row tokens** — own blake3 row tokens. arrow-row keys are comparable only within one `RowConverter`, and these tokens persist.
- **Plan traversal** — `traversal.rs`. DataFusion `TreeNode` does not memoize shared `Arc` subtrees; consolidate the other walkers into it.
- **Tear selection** — the exact tear MILP. No pinned graph library offers an exact minimum feedback arc set; the HiGHS MILP is backed by an independent DAG witness.
- **Clarabel** — `conic.rs` cone violation and `svec`. Clarabel's `margins` is `unreachable!()` for exp/pow cones and `mat_to_svec` is `pub(crate)`.
- **HiGHS bindings** — `highs` plus `highs-sys`. The safe crate lacks callbacks, IIS, ranging and basis.
- **SuiteSparse** — the direct `suitesparse_sys` dependency unifies features for static KLU/AMD/COLAMD/BTF.
- **Guarded execution** — the guarded staged program. Symbolica's `IfElse` lacks typed domain rejection and fallible multi-output providers; the reason is stated at `guarded.rs:4-7`.

## 12. Decision

**Decision: Revise.**

The pivot's library choices are sound and genuinely library-owned. Mathematics, derivatives, properties, structure, iteration and factorization all come from qualified libraries, with guard survival and FFI containment protected by tests. But all eight core gates and all three profile gates fail on in-scope behaviour:

- A supported syntax is refused (literal powers).
- A library effect can abort the process, and another makes numerics order-dependent.
- Solve and fit outcomes overclaim, and the durable vocabulary is untyped.
- Scaling and several physical conventions are not model-owned.
- The recycle/initialization journey and the authored material system have no production route.
- The publication lifecycle cannot republish.
- The qualification tooling can certify untested source.

The competing-authority and unbacked-capability items (F01, F02, F18, F27) fall under the "Reject or Revise" rule. Revision is sufficient because none is structural to the library architecture.

**Remaining limits.**
- Nothing was built, tested or benchmarked by the lead. F14 and F04 are traced, not executed. The F08 entropy offset is analytic.
- Findings from sub-review evidence without **[lead]** re-reading were spot-checked for plausibility, not re-derived line by line.
