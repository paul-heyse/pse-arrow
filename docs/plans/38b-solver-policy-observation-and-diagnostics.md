# Plan 38b: Solver policy, observation and diagnostics

## Purpose and baseline

This companion owns the common governing policy required by [Plan 38](38-efficiency-and-solver-target.md), correcting F09/F11/F12 and the solver impacts. It consumes [pipeline evidence](../design_review/evidence/efficiency-and-solver-target-audit-2026-10-12/pipeline-diagnostics-and-advice.md) and [fresh independent assessment](../design_review/evidence/efficiency-and-solver-target-audit-2026-10-12/independent-target-assessment.md). Blueprint §15–§18/§19.2 describe current contracts; their accepted amendment routes are coordinator G0 dependencies, not edits during authoring.

At the inspected baseline, routing has contextual pending/refused/supported-unprepared/ready distinctions, strategy has pure admission/next/work operations with injected effects, WorkEvidence carries optional counters, and original assessment/terminal vetoes/aggregate budgets already exist. Preference and statement-order composition still differ across Auto, block, workflow and adapter paths. Preserve the existing walker and strengthen its authoritative policy; do not add a parallel planner or universal serializable language.

A1–A4 supply locally owned scientific products; C1/C3 supply actual native profile/observation facts; D supplies representation-specific scientific maps/controllers. Storage is an optional record consumer. **Interface-checked** baseline and **Proposed** target/checks are distinct; authoring ran no numerical work.

## B1 — Scientific request and contextual candidate interpretation

Consume an immutable original problem, analysis goal, physical/provider context, formulation/derivative/representation witnesses, domain/bounds, exact explicit selection or Auto, requested assurance/accuracy, branch/start/reuse policy, reformulation/global/multistart permissions and finite original budget. Ordinary typed functions/products are sufficient. Do not conflate native class suitability, missing evidence/artifacts, option/profile incompatibility and placement unavailability.

Retain whole contextual assessment: static routing::admit alone is not adapter assess with actual settings/artifacts. Builders for algebraic roots/NLP/coefficient/cones, initialization/recycle, fitting and dynamics supply candidates and preparation demands. A selected method can request a derivative action without a full Jacobian; expensive class/condition evidence is demand-driven. Unknown is not false. Explicit backend selection forbids silent replacement. Bounds are not VI complementarity; least-squares stationarity is not a root; feasible/stationary/certified outcomes grant distinct permission.

Resource-aware preference is legitimate among permitted equivalent profiles when explicitly selected. Ordinary pressure normally changes placement; profile/width substitution is recorded and cannot change branch/accuracy meaning silently. Actual resource declarations belong to C4, not a static mathematical rank.

**Targeted acceptance:** pure injected candidate inventories with no store/native startup; explicit/Auto, pending evidence versus refusal, context/artifact mismatch, root/LS/VI/global permission, branch/start/reformulation denial and requested width versus capacity. Same contract reaches existing current workflow consumers; a common output record alone is insufficient migration.

## B2 — One policy and safeguarded dynamic routing

Use reliable mathematical features first, then synchronous observed evidence, then optional advisory preference. Absorb automatic_operations/backend_alternatives, block/initialization selectors, presolve/recycle, fitting derivative/Hessian, dynamics Auto and native linear-profile defaults through one governing preference/transition meaning. Class-specific builders remain separate; C owns actual numerical implementations and D the scientific controller/map. Preserve current pure strategy effect boundary and typed OriginalConclusion.

A transition consumes the prior typed cause, retained proposal/evidence, original conclusion and remaining aggregate work/deadline. Cancellation/deadline, contract invalidity, panic and infrastructure/resource failure are terminal vetoes. A policy stop may supply a start proposal but never a solution by status alone. No retry/successor resets work or clocks. Permitted domain/numerical failures can trigger bounded library-owned globalization, changed representation/profile or declared continuation; global search/certification/branch changes need explicit permission.

Best merit compares original normalized physical feasibility/residual/domain/branch, with deterministic ties and provenance; objective alone is insufficient. Projection/normalization/start conversion is a named transform and rescreened. First-factor singularity is an observation, not necessarily available at binding. Successor mapping preserves original row/variable/multiplier interpretation. Causal/reduced block results retain fresh assembled original assessment; authored definitions never mutate.

**Targeted acceptance:** scripted failed/policy-stopped candidate and screened successor; different explicit branch/global permissions; unavailable condition evidence; aggregate exhaustion and cancellation prohibit further recovery; proposals that satisfy LS but fail roots remain unusable; deterministic tie/start transform; native execution small examples preserve independent original classification. Remove old independent decision trees and their mechanism tests after migrated callers pass; retain semantically distinct scientific controllers.

## B3 — Typed observations and compact attempt evidence

Extend existing WorkEvidence rather than claiming it absent. Promote available native iterations/evaluations/linear/phase facts with family-specific meanings, optional absence and achieved profile. Include terminal cause, original assessment, request/effective controls, start/reuse/policy history, decision rationale and numerical confidence. Actual producer fields define meaning; parsing arbitrary text or filling unknown with zero is forbidden. FERAL perturbation/tiny-pivot observations do not prove exact inertia.

Decision observations are bounded and synchronous. Ordinary progress uses a separate bounded nonblocking tap with explicit loss/partiality; dropped telemetry cannot change convergence or transitions. Strict delivery, if supported, is explicit and bounded by its real contract. One in-memory summary serves user explanation, D's controllers, optional persistence and measurement. No per-event durable journal or accounting framework is required. Recording failure has explicit required-versus-optional behavior under E2 and cannot masquerade as mathematical failure/success.

Raw recycle samples come from D2's G evaluation, distinguishing actual outer iterates, trial/perturbation/failed evaluations, physical Err/Tol and acceleration step norm. Trace/record buffering, phase timing and queue/execution/assessment intervals share finite capacity; overlapping times are not summed as disjoint cost. C3 owns native getters/callbacks; B owns interpretation.

**Targeted acceptance:** available versus missing counters, two methods with different iteration semantics, final typed terminal outcome despite dropped ordinary tap, storage unavailable with required/optional sink distinction, bounded long histories and exact raw-map samples. Capability documentation/strings move with actual producer facts, not invented fields. Needed numeric observation is product behavior; performance benefit remains unmeasured until a campaign names conditions.

## B4 — Bounded diagnosis and replay

Preserve existing automatic model-associated boundary diagnostics and the 25-kind catalog. Add compact automatic failure summaries from retained final/best accepted evidence and optional richer native/rank/elastic/deletion/domain/derivative analysis when useful. Every finding maps through exact original coordinates/scales and records unavailable or partial evidence. C6 owns distinct sparse versus SVD diagnostic conventions; no QR vector is labeled a singular mode.

Hard cancellation/deadline takes precedence. At exhaustion, use retained evidence or a reserved/separately requested diagnostic allocation; do not silently continue numerical work. Restoration snapshots use C3's actual available original-space callback data; absent internal slacks stay absent. Catalog counts or successful residual checks do not qualify every derivative/domain/native-status contract.

Replay levels are explicit: input reconstruction, effective-decision replay, tolerant numerical rerun and actual native continuation. Export an immutable closure of authored/case/provider/physical inputs, interpretation/build/runtime premises, executed decisions/observations, effective settings/advice/permutation/limits, starts and transforms/branches. Native checkpoints have library-specific lifetimes; a point vector is not resumable state. Current export/storage can realize replay before a journal redesign. Frozen policy does not guarantee wall-clock/observer/concurrent execution identity.

**Targeted acceptance:** reconstruct without mutable current history; missing provider/reference/build refuses explicitly; branch/start/effective advice preserved; exhausted-budget summaries do no unadmitted solver work; external stop returns partial diagnostic truth; existing model diagnostics remain automatic; exported interrupted trajectory does not claim full horizon/native continuation.

## B5 — Advisory history with honest inference

Advisory history is optional and cannot create eligibility, override explicit choices or authorize branch/global work. Its absence leaves a complete declared baseline policy. Freeze/materialize actual effective ranking/tuning/limits used by a study and retain that dependency through resume, not merely a mutable snapshot id. Independent points and declared numerical chains remain distinct; D/C enforce actual start/state history.

Define the intended descriptive comparison/cohort before ranking. Preparation, queue, native execution, assessment and publication intervals have actual semantics. Budget exhaustion, policy preemption, user cancellation, infrastructure interruption and terminal numerical failure are different outcomes; they can be informative/competing censoring. Conditioning on plan position/start does not automatically remove adaptive exposure/survivor bias. Begin with conservative within-cohort summaries/ties and record limited support. More ambitious estimators require a separately justified question, not a mandatory research platform.

Finite budgets do not guarantee every admitted candidate runs. Record allocation/skipped opportunities and enforce branch/accuracy/assurance equivalence when reordering can change a nonconvex result. Statistical/tolerance/bitwise determinism labels must name the actual comparison and native conditions. A resource/time-dependent policy may be explainable without identical rerun paths.

**Targeted acceptance:** missing/incompatible advice restores baseline; effective materialized choices survive mutable-history changes/resume; nonconvex branch permission under reorder; failures/stops/interruption remain separate; no invented zero-duration/iteration data; finite budget and parent clocks survive advisory tuning. End-to-end benefit is a separate conditioned measurement, not acceptance of the policy's truth.

### A mistake made and corrected

Initial replay retained some post-preparation defaults and execution scopes instead of
all original caller inputs. Independent inspection exposed requested-start loss,
late copy admission, reused cancellation/clock state, discarded failed callable reports,
unbounded graph expansion and per-node compiler-premise loss. The implementation now
captures at the actual producer, precharges expanded metadata and reconstructs through
the original admission owner with fresh execution state. The Full horizon control then
exposed a separate original-request loss behind its materialized prefix; retaining the
request repaired faithful reconstruction, including cancellation before step one.

Two initial native fixtures had invalid premises: a SCIP alternative lacked required
factorable evidence and a POUNCE iteration-limit recovery lacked observed quality
escalation. The controls were corrected to actual compatible HiGHS Simplex/IPM profiles
and actual POUNCE statistics, preserving the production admission/recovery barriers.
The initial graph-depth refusal happened after expensive encoding; a preliminary structure
pass now refuses first. Earlier mixed runs (13 tests: four failed; 16: two failed; 60:
one failed) remain failed invocations; corrected controls passed in the final selection.

Python validation first encountered shared temporary-directory ownership and a deliberately
quiesced canonical profile. The new store-free controls use an owned temporary root and
explicit ephemeral runtimes; neither shared state was changed. They then exposed a real
SIGSEGV while waiting for the first solve. GDB located task-local polling of the large
inline supervisor; synchronous heap boxing repaired the reproducer without changing worker
stack configuration or cancellation semantics. Stack exhaustion is a supported inference,
not a guard-page measurement. Subsequent strict decoding exposed feature-dependent shooting
schemas and infinite native option values becoming null. Unconditional transport types
and the existing Observation codec repaired those boundaries without relaxing decoding.
Generated readback also corrected a summary-local type alias that initially referred to the
terminal observation vocabulary instead of the numeric diagnostic type; the final Python
summary roundtrip exercises the actual corrected schema and payload together.
