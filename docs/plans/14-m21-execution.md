## Settled contracts

Symbolica/Numerica own mathematics; FeOS/num-dual own thermodynamics; faer owns
linear algebra; pounce-presolve owns matching/DM/BTF and admitted presolve. Existing
petgraph/rustworkx projections, Salsa dependency tracking, DataFusion retention and
exact Delta publication retain their current consumers. No new math IR, numerical
fallback, cache or generic algorithm framework is introduced.

Source declarations lose arbitrary policy hashes. The compiler derives guarded-real
semantics. Physical envelopes are explicit, finite and reject outside-range states;
declared operating windows do not assert empirical certification. Acceptance fixtures
use 250–500 K, 0 < density <= 25000 mol/m³, 0 < pressure <= 100 MPa and interior
ternary composition. Provider identity includes the envelope. Unsupported extrapolation
is not implemented. Balances derive from typed signed contributions with source IDs;
native status, mathematical feasibility and independent physical checks remain separate.

Root admission requires a complete square matching. NLP retains optimization degrees
of freedom; coefficient/conic routes retain native presolve semantics. Dynamics checks
the algebraic partition. Structural matching is not numerical rank. faer verifies scaled
implicit responses with normwise backward error bounded by 64*max(1,n)*f64::EPSILON.

Generated declarations/results change atomically with callers; no compatibility schema
or API is retained. Source-authoring broadcast/conversion syntax remains only for its
current inspection/editing consumers, explicitly unavailable for numerical execution.

## Outcome

**Implemented:** all seven packets and their paired deletions are complete. The
[bounded implementation review](../design_review/reviews/design_review_m21-design-closure_2026-09-24.md)
accepts these mechanisms and records current consumer/library dispositions. It does
not supply independent M22 approval. M00–M21 implementation is closed; M22 is next.

A mistake corrected during execution was retaining a compiler-level refusal test
for a function now rejected by the parser. The assertion now tests the actual
admission boundary. Consumer review also corrected mutable fixture aliasing and
ensured replicated process blocks carry their authoritative balance declarations.

Deliberate deviations: operating windows are explicit declarations, not empirical
certification; physical-only inference vocabulary and authoring Convert/Broadcast
remain for their current consumers without numerical availability. Existing Salsa,
graph, Arrow/DataFusion and exact Delta owners remain. No compatibility numerical
engine, host quadrature, alternate result schema or independent-review substitute
was introduced. Proposed ADR-0082–0084 and the blueprint require formal reconciliation
through M22's decision/design PR workflow.
