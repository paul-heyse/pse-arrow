## Target and decisions settled during authoring

Retain authored scientific authority, exact derivative axes, class-specific library algorithms, immutable prepared products and independent original-space qualification. Change physical evaluation and native-state lifetimes inside their existing owners. An immutable layout describes where values and contributions go; attempt-owned buffers hold the current trial. Numerical validity belongs to the exact inputs, physical context, order and selected branch that established it. Resource observations, cancellation and deadlines stay live.

The numerical target has five deliberate limits. First, Symbolica 3.0.1 remains the interpreted evaluator: common scalar optimization and demand-specific instantiation are feasible through its public APIs, but a shared immutable instruction program with independent stacks is not. Its `ExpressionEvaluator` owns stack/instructions; `ProgramView` and `program()` are `pub(super)`. The portable skill covers 3.0.0; the actual 3.0.1 registry source was checked. Second, scratch transfer is optional exclusive transfer after drain/reset, never shared simultaneous mutation. Third, cubic ownership/memo improvements proceed independently of replacing certified isolation; no unproved candidate-only fast path is selected. Fourth, Root response initially retains public singular-value rank/cutoff semantics. Fifth, shooting makes requested/achieved order explicit; eager First evaluation is an intentional policy option when observed callback demand warrants it.

**RC13:** accepted 2026-10-11 as recorded in the coordinator. The clarification of blueprint §14.3 retains DP-19: an old attempt relinquishes empty scratch only after native/provider/callback drain, caches and controls are reset, and the receiving attempt exclusively acquires it with correct charges. Keeping literal fresh allocation limits the work to lazy per-order cloning. This does not authorize the simultaneous F18 coefficient sharing.

**RC14:** retain blueprint §15.5.1 and current `square_response::Evidence` meaning initially. That type explicitly defines `cutoff` as an absolute singular-value cutoff. Sparse QR rank would need a separate bounded numerical-method decision covering evidence representation, thresholds and consumer migration, followed by operator confirmation. Structural matching plus backward error is rejected as a numerical rank substitute. Sparse solve/factor sharing does not depend on changing rank semantics.

Sources: original principal F16–F22/RC13–RC14; complete original inquiries B, C and L1; audit mathematical-native-execution and principal A03–A05; blueprint §7, §14.1/§14.3–§14.5, §15/§15.5.1; current bindings and Cargo pins. Context7 resolved/queried Symbolica evaluation, faer factor ownership and SUNDIALS reinitialization; release-specific decisions use local pinned source. No utilization catalog or capability maps were consumed.

## P-C1 — Compile operation-shaped bindings and compact trial results

**Coverage:** F16; B-01–B-04; C-01; callback-allocation and dynamic-scatter opportunities. Producers are `pse-math::{binding,assembly,execution,jets}` and applicability plans. Consumers are `AlgebraicOracle`, `DynamicWorker`, the TNLP/foreign callback bridges and independent original-case evaluation.

At assembly construction derive immutable coordinate/fixed/parameter offsets, per-instance formal gathers with admitted conversions, contribution destinations, demand-cache/output offsets, packed Hessian components and guard/applicability read sets. Repeated semantic sources remain aliases; formal derivative coordinates retain their declared order. A value rebind supplies a separately owned fixed/parameter vector. Missing scalars, malformed maps and duplicate formals are refused before native entry. The callback accepts the dense trial slice instead of inserting every coordinate into `CaseValues.scalars` and rediscovering these maps. Semantic identities remain the boundary for authoring, rebinding, diagnostics, final reconstruction and PS-10.

Retain reusable input/bit/result buffers and atomic scratch-to-caller publication. Fill only the requested layout's frame extent, retaining NaN poisoning of every readable unassigned slot. Keep Second-order output jets packed internally; expand the existing dense symmetric public `Evaluation` only where its declared consumer, including implicit IFT, actually needs it. Dense Hessians are currently allocated only for Second, not every callback; the independent confirmed issue is maximum-frame filling at smaller orders. Constraint/Objective/All caches may share an achieved-order result only for identical output selection, axes and inputs; never evaluate an inactive branch to manufacture reuse.

Compile guard and applicability local read maps; do not move typed guard/branch barriers into Symbolica `IfElse`. Applicability stores compact node/outcome/input witnesses for the exact successful trial and hydrates full observations on consumed final evidence or refusal. Failure invalidates that trial's cache/witness, preventing stale evidence from a previous candidate. Hydration retains clause, instance, permissions, values and causal lineage.

Finiteness is checked before the first provider/native consumer relies on a value, and after new arithmetic, conversion, normalization or independent state production. Validated same-trial guarantees can cross immutable operations; final persistence is not the first relevant boundary. Keep callback panic containment, typed latching, checks around computation and atomic publication. Static callback accounting keys replace allocated strings, but the actual work charge is preserved. Precompute IDAS Jacobian scatters, and remove avoidable `DynamicWorker` sparse-matrix clones where borrowed or reused results satisfy its actual cache ownership.

**Acceptance/removal:** targeted alias, affine overflow, signed-zero, permuted-axis, missing-value, branch/domain, First/Second symmetry, failed-cache, attribution and cancellation controls; bit-identical mathematical outputs where execution order stays identical. Verify selected result/order sizes and exact observation equivalence. Delete callback map transport, repeated duplicate sets/searches, wide guard frames and internal dense Hessian expansion after every caller moves. Preserve public dense materialization only as its explicit boundary contract. Coordinate P-C1's actual buffer extents with F10 admission; no hidden lazy allocation.

## P-C2 — Optimize scalar stages once and instantiate actual derivative demand

**Coverage:** F17; B-07/B-08; L1-03; B-P2/L1-P4. Owners: `execution::{compile_scope,compile_stages,CompiledBody::worker_scoped}`, `library::{exact_evaluator,admission::bounded_evaluator}`, assembly `LocalDemand`, compiler artifact requests and runtime worker construction.

Separate source/scalar admission and exact scalar optimization from per-order expansion admission. Construct an exact optimized evaluator once for each actual scalar block/read-set/options tuple, including repeated Value-only guard bodies. Clone that public evaluator into each demanded `vectorize(Dualizer)`/`map_coeff` product, preserving structural Taylor zeros and block-local axes. Provider lifts share only genuinely common preparation, retaining order-specific work. Do not claim preparation becomes three times faster: source establishes up to three scalar optimizer invocations; derivative preparation and vectorization remain different work.

Give Objective and Constraints their actual maximum consumed order (normally First), and All the necessary Second ceiling. When an identical output/coordinate selection serves several groups, deduplicate to their maximum demanded ceiling rather than accidentally selecting the lowest first request. Artifact/admission identities must represent the resulting ordered selection, ceiling, directional mode, providers and optimizer profile. Old persisted descriptions are readmitted/rebuilt through existing identity rules; changing physical layout alone is not permission to change semantic hashing.

Worker construction initially keeps no mutable program for unrequested orders. First use clones an already prepared order product under its admitted allowance; it does not perform unbounded symbolic compilation in a callback. Charges grow before allocation or remain within a prepaid complete extent. Cold, First-only, quasi-Newton and Value-only routes therefore need not clone Second instructions. Original PS-10 workers remain independent.

Under accepted RC13, add one lane-local transfer seam keyed by exact assembly/program/profile compatibility. Transfer only poisoned/reset frames, instruction-bearing evaluator storage and reusable empty buffers. Discard providers, memo products, applicability witnesses, numerical factors, failure latches and scope/cancellation handles unless a separate existing native session contract expressly owns them. Reset failure destroys the candidate transfer object. Idle transferred storage remains charged to its actual lane owner; charge release occurs on destruction/drain, not on logical attempt completion. No global worker cache is needed.

**Acceptance/removal:** count exact scalar builds per distinct block, exercise demand ceilings/deduplication, request upgrades, budget failure before lazy growth, interruption and independent verification. With transfer enabled, run sequential-attempt controls proving no old values, providers, failures or cancellation owner survive and that no overlap is possible. Delete eager all-order worker clones and repeated scalar optimizer loops. An upstream immutable-program/scratch API is a later bounded library investigation, not a private-API patch or prerequisite.

## P-C3 — Separate cubic scratch, completeness and implicit memo validity

**Coverage:** F18; B-05/B-06; L1-04; near-critical B-P3/L1-P3 investigation. Owners: `implicit::{Factory::create_scoped,Nested::evaluate,Problem::{verify,derivatives}}`, `implicit_accelerators::Cubic`, `implicit_cubic::CubicRoots`, compiled Provider stages and native inner-solver injection.

Prepared cubic admission owns immutable coefficient program/parameter descriptors. Attempt/provider construction creates private coefficient evaluator scratch and accounts it there. Evolve the factory-to-inner-solver construction seam so a retained immutable solver definition can create an exclusive worker; update injected native/affine solvers and tests as required rather than making every shared solver mutable by accident. Current `Mutex` protects only `.evaluate(parameters, coefficients)`; Rational conversion, isolation, refinement and verification run after its guard drops. Removing the shared coefficient lock is an ownership correction, not proof that complete root solves were serialized.

Retain exact polynomial isolation/refinement initially. It certifies the polynomial formed from evaluated f64 coefficients, so the independent original residual/bounds/branch check remains mandatory. Schedule a bounded algorithm decision before replacing this path: compare Symbolica float `roots`/`roots_hot_start` candidates, library-owned interval/certified isolation and restricted-branch exact work. The selected fast scope must establish complete branch root count/separation, not merely small residual or coefficient backward error. Degree reduction, repeated/near-critical roots, boundaries and uncertain rounding all fall back to the existing certified path. Symbolica documentation explicitly supplies no root-error certificate for Aberth. A handwritten Newton/bisection controller is not selected without a demonstrated library gap and PS-09 review. If no fitting completeness mechanism is established, retain exact isolation, record measured limitations and keep this sub-obligation open; do not mark all F18 resolved from the mutex fix.

Memo products retain separate achieved Value/First/Second validity, complete input bit patterns, immutable problem/provider/configuration/solver identity, starts, tolerances, branch/anchor and selector premises. Existing `numerical_product_key` frames compiled order and options; achieved order is separately stored. The new hit path may bypass unchanged configuration/anchor/residual/selection work only where their dependencies are actually covered. A Value hit never establishes nonsingular First/Second IFT or neighborhood support. Upgrade derivatives and branch proof at the higher order before publication. Reuse a residual jet for the same residual check only when it supplies the identical original obligation. Deadlines, cancellation and remaining work are never cached; a hit still observes them.

Compile provider fan-out per actual spec/input/active branch, requesting the maximum consumed order once only where evaluation/refusal order and attribution remain equivalent. Otherwise preserve stage order and reuse the product opportunistically. Failure clears validity; new numerical states are independently checked.

**Acceptance/removal:** ordinary, degree-reduced, repeated/near-critical and interval-boundary cubics against the old exact oracle; ambiguity refusal, original residual checks and cancellation; Value→First→Second upgrades, changed hints/start/tolerance/anchor/provider, same-bit hits and selector refusals. Delete shared mutable coefficient scratch and duplicated same-premise verification only after these controls establish carried validity. Fast algorithm selection has its own decision and acceptance; it is not inferred from a microbenchmark.

## P-C4 — Retain conditional allocations and execute block sequences at operation grain

**Coverage:** F19; C-02/C-06; conditional-row filtering, warm-start and presolve opportunities. Owners: runtime `workflow/strategies/conditional::{UnitProgram,UnitWorker}`, `math/initialization`, native `execution::Retained`, KINSOL and PS-08 commit policy.

One enclosing CausalMap/attempt owns each unit's compact binding, evaluator/oracle and compatible native session capacity. Refill selected external/fixed inputs; compute compatibility from the consumed unit inputs and structural/profile context. Reconstruct full semantic values only at the original-state boundary. Remove whole-flowsheet clones/hashes from every unit trial. Distinguish allocation/symbolic reuse from numeric reuse: changed tears change Jacobian values; KINSOL owns setup refresh and stale-setup policy. Retaining a numeric factor unconditionally is rejected.

Default starts remain the authored cold starts, with native reset/refresh behavior explicit enough to preserve the declared deterministic map/outcome. Previous committed roots become declared recorded starts only when existing uniqueness/branch policy admits them, or a screened proposal passes that same policy. Session retention alone must not silently alter the branch/start contract. Native/provider references and charges survive until their real enclosing owner drains.

Initialization prepares selected boundaries and row maps once, then executes a sequence within one admitted operation on its native owner. Each BTF block retains its declared strategy, distinct report, independent original qualification, commit/rollback and temporary-overlay restoration. A scalar implicit equation is not an explicit assignment; direct execution requires an actual explicit expression/proof. Larger/failing blocks invoke the existing full strategy locally, preserving block attribution and previous-accepted policy. The independent assessment program can be retained immutably; each new committed state uses fresh/reset independent assessment scratch, never the solver's unchecked cache.

**Acceptance/removal:** deterministic repeated tear inputs, branch-ambiguous and stale-setup controls, changed profile/structure, block failure after earlier commits, strategy escalation, cancellation between/inside blocks, overlay restoration and native drain. Delete per-evaluation `Retained::default`, full-case transport and per-block external task/step crossings once the replacement carries all semantic outcomes. Presolve reuse remains a separately bounded investigation below, not an excuse to skip per-block original checks.

## P-C5 — Share only a valid same-point Root factor; retain rank meaning

**Coverage:** F20; C-03/L1-01; fitting observation-rank adjacency. Producers: runtime `math/solves::{root_response,fresh_root_predictor_at}`; native `square_response` and `square_response/actions`; consumers: public Root responses, study prediction and fitting.

Build fresh original state/parameter partials once when both response and predictor are requested at the same independently qualified point. Bind the product to exact semantic dependencies, bit-exact physical point, state/row order, bounds, normalization, physical budgets and provider/branch context. The existing normalized matrix is `A_ij = Fx_ij * variable_scale_j / row_scale_i`. One sparse faer numeric factor solves multiple parameter RHS and predictor actions only for this same matrix. The predictor is not requested on every Root solve, and an optional public response need not retain a predictor. Any derivative, point, scale or ordering change invalidates numerical factors; structural pattern alone permits only symbolic/storage reuse.

Keep bounded dense spectrum computation for the current singular-value rank/cutoff evidence, with no U/V vectors requested. Replace the extra dense LU and dense backward check by the valid sparse factor/solve/check. Physical back-mapping, inactive-bound neighborhood checks, original residual budgets, independent withholding and finite checks remain. Fitting's observation/sensitivity rank is a different matrix from Fx and cannot inherit the Root factor's rank conclusion.

Additional foundation prerequisite: `SparseFactor::allowance(n)` currently reserves `64*n*n + 512*n + 4096` bytes. Its sparse stored matrix does not eliminate that dense conservative allowance. Before claiming large sparse support, investigate faer symbolic/scratch and numeric-fill allocation contracts under admitted growth. Numerical pivoting can create real fill: do not substitute an nnz guess as a hard bound. Select a source-supported fill bound/growth mechanism or explicitly retain the bounded supported scope. A library allocation seam may require upstream work; factor sharing alone does not settle it.

Schedule an optional rank-method investigation separately: qualified sparse rank-revealing QR/SPQR, method-tagged evidence, scaling/pivot/threshold semantics and near-cutoff comparison. `suitesparse_sys 0.1.4` exposes optional `spqr`, currently disabled; a feature toggle does not qualify the numerical method or native ABI. Return a concrete design for operator decision before migration. Retaining current evidence leaves dense spectrum cost/large-n withholding explicit; full F20 stays open unless that scope is deliberately accepted or a qualified alternative lands.

**Acceptance/removal:** same-point shared construction counts, sparse/dense derivative agreement, independent perturbed-root controls, mismatched-point/scale/row/provider refusal, near-cutoff and numerically rank-deficient structurally square controls, memory refusal and physical back-mapping. Existing `fresh_sparse_actions_reuse_factor_and_match_independent_perturbed_roots` and `parameter_actions_share_fresh_factor_without_dense_responses` are useful focused controls, not rank-method qualification. Delete the duplicate dense LU/Jacobian evaluation after consumers move; keep the spectrum boundary explicitly demanded.

## P-C6 — SCC-local tear constraints with global decision coupling preserved

**Coverage:** F21/C-05. Owners: `pse-structural::flowsheet::FlowGraph` and native `tears::{construction_allocation_bound,compile,solve}`.

Choose one HiGHS model with SCC-local order variables/constraints and globally shared decision columns. This handles grouped decisions spanning SCCs without an error-prone independent solve/merge protocol. Omit inter-SCC order rows; bound each SCC's order and big-M by its own size. Keep singleton self-loop constraints; trivial singleton components without loops need no order variables. Preserve every authored mandatory/forbidden/group cost decision, including groups having only acyclic edges. Solve cost is counted once per shared group. Independent blocks may later be split only after their decision incidence proves independence.

Apply the existing whole-graph policy/DAG witness to the returned set, and preserve native incumbent/limit/optimality meaning. A time limit can have a usable incumbent; do not infer inevitable failure. Lazy cycle generation is an alternative only if measurements justify its callback/termination complexity.

**Acceptance/removal:** grouped multi-SCC costs, mandatory acyclic decisions, forbidden cycles, self loops, disconnected graphs and limited incumbents; compare optimum/witness with the old global formulation on bounded fixtures. Delete global inter-SCC rows/big-M and update allocation bounds after replacement acceptance. This is once-per-structure work; give it lower consequence priority than callbacks without inventing timing claims.

## P-C8 — Coordinate IBEX exclusion at actual quiescence

**Coverage:** audit A03/C-A01; F10/faer integration. Extend existing `ComputeAdmission` ownership to proof routes without weakening process-global IBEX safety. At a quiescent synchronous operation, an exclusion wait releases its active compute allowance; before native entry it reacquires the same allowance against the original Execution/scope/stop. Retained proof/attempt/native memory stays charged. Poisoning, cancellation, deadline, unwind and failed reacquisition release the library guard and preserve typed evidence/drain.

Use the coordination owner's resident-session/population token separately from the active job/CPU lease. Queued stages acquire their transient/construction demand before active dispatch; no resident native session or empty retained evaluator holds an active job merely to preserve memory. Nested synchronous work borrows the enclosing active lease; genuinely independent child work waits only after quiescent parent release. Do not grow demand while retaining CPU that the required child admission needs.

Never hold the IBEX guard across blocking compute reacquisition. An active-team callback may legitimately keep its team's allowance while waiting for IBEX; if a quiescent waiter acquired IBEX and then waited for that allowance, the two would deadlock. After observing library availability, obtain both resources without hold-and-wait: if immediate compute reacquisition fails, release the library guard and retry through the original-clock cancellable owner, or use an equivalent request-local coordinated admission. Any fairness/backoff keeps finite waiters and does not introduce a fresh deadline. Native entry requires both owned resources. Mere cancellation cleanup after a blocked reacquisition is insufficient.

Cover point arithmetic, promote/connect/refine, action/neighborhood, chain and interval-cover entrypoints through one owned admission helper, including current optional-Execution variants. Do not create a fresh deadline for a legacy entrypoint. An active native team callback cannot release its whole team's allowance while other threads still work. Such routes retain team charges unless a genuine request-local quiescent owner is established; this is a visible support/lifetime distinction, not a blanket `pause_compute` insertion. The current pause/resume bridge is feature-gated only for HiGHS/Uno/PETSc, so extend its applicable feature boundary deliberately.

Pass an explicitly admitted faer `Par` through implicit factor/scratch construction and solves, defaulting to Seq for nested blocks. Never mutate global defaults. The coordination owner controls operation capacity; math consumes that admission and uses the same Par for scratch sizing and execution.

**Acceptance/removal:** holder + quiescent queued proof + unrelated compute job; mixed active-team waiter plus quiescent waiter under saturated CPU, proving progress without a guard/permit cycle; queued cancellation/deadline and failed reacquisition; no native work before reacquisition; active-team control proving its charge stays held; all IBEX request variants. Delete duplicated unmanaged lock-wait loops after replacement. Unsafe team contexts remain explicitly charged, not mislabeled as released capacity.

## P-C9 — Make surrogate snapshots and shooting derivative demand explicit

**Coverage:** audit A04/A05 (C-A02/C-A03). Surrogate actual EgorState stays solely with its retained egobox worker. Advance returns compact initialized/iteration/termination/disabled state, proposal and work counters; runtime actor consumes that summary. Full owned state snapshots become an explicit charged request, with all public/test consumers migrated. Remove the wrapper's automatic history copy and `worker.state.clone()` per Advance. Pinned 0.38.1 Clone owns history arrays/clustering/theta state; it is not proof of copying a GP covariance matrix. Preserve RNG, actual next_iter/init state, proposal screening, failure accounting and stop/drain acknowledgment.

Shooting `evaluate(x, requested_order)` caches bit-exact x plus achieved order and source/scope compatibility. Value requests integrate primal/outputs/quadratures only. First requests produce all required continuity/path/terminal derivatives; upgrades perform supported new integration if no compatible native checkpoint/session can actually be reused. Integral adjoints retain their independent demand. A report is not a retained native checkpoint. Upgrades publish a coherent refreshed point; sensitivity error control may change primal integration steps, so retain declared numerical tolerance/qualification rather than promise cross-mode bit identity. No finite-difference substitution.

Expose a deliberate operation policy: demanded-order by default; eager First only where backend callback evidence supports amortization. Cache achieved capability under either policy. Compare rejected value trials versus upgraded accepted points before selecting backend defaults; do not assume lazy is always faster. Preserve scheduled changes, anchors, physical scaling, derivative axes, original qualification and the original deadline.

**Acceptance/removal:** identical seeded surrogate proposal/termination sequence with explicit snapshot equivalence and no automatic history clone; snapshot cancellation/charges. Shooting value-only rejected trials invoke no sensitivity integration under demanded policy; same-point upgrade and derivative comparison cover continuity/path/terminal/integral terms, scheduled jumps and cancellation. Delete unconditional forward sensitivity and automatic snapshot transport after consumers migrate.

## Verification and completion boundary

P-C1 enables compact conditional transport; P-C2 and P-C3 can proceed independently; P-C4 depends on layout/native lifetime contracts; P-C5 depends on same-point product identity and honest fill admission; P-C6/P-C7 are independent; P-C8 shares coordination ownership; P-C9 shares demand/publication ownership. Rule-dependent transfer or method substitution waits for its actual decision. Each package uses touched-crate compile checks and targeted correctness controls through `scripts/pse-env --`, native mode when required and explicit force-validation for the actual Arrow closure. Run scoped integration/scientific journeys, performance campaigns and static hygiene once functional scope is complete; the root owns turn-end formatting.

B-P1/C-P1/H-P5 callback profiles, B-P2/L1-P4 construction/rebind, B-P3/L1-P3 cubic call frequency/near-critical controls, C-P2 conditional recycle, C-P3 presolve, C-P4 tear structure and L1-P2 sparse response are proposed evidence choices tied to decisions. Earlier review percentage thresholds are not universal acceptance gates. Measure callback sequences for shooting and real copied bytes for surrogate if priority/default policy is contested. Existing ordinary PC-SAFT fixtures do not establish many-small-body or many-change scaling. Report actual commands/mode/scope/zero baseline; no new mandatory receipt framework or performance SLA is introduced.

Closing the numerical scope requires deletion of every replaced mechanism, explicit disposition of retained investigations, truthful rank/algorithm/support limits and the relevant independent original checks. Architecture fitness, scientific adequacy and measured performance remain separate outcomes. No implementation or speed is established by this plan.
