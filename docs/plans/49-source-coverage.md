# Plan 49: Source coverage and capability routing

## How to use this appendix

This is navigation from the complete revised review and its supporting artifacts to the
proposed series. The [coordinator](49-library-native-remediation.md) alone owns mutable
finding dispositions, package state, inquiry outcomes and rule decisions. Tables below
explain selection/routing; they do not independently close work. The original scope was
in-use libraries only. The operator expanded authoring to the new SurrealDB/Symbolica
integrations and explicitly selected SurrealMX 1.0; current library capability assessment
can therefore supersede a source remedy without dropping its underlying obligation.

**Interface-checked:** source documents, tagged/library APIs and relevant current owners.
**Proposed:** all new remedies. Original Tested/Measured receipts retain their original
conditions. The principal review's §§1–14 and the net-change companion govern the integrated
review judgment; §15 preserves historical challenge dispositions. No first-draft inventory
or historical challenge is promoted to a new accepted design requirement.
