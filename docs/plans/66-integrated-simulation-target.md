# Integrated simulation target

## Authority, target and baseline

**Plan66 is the sole go-forward plan.** The maintainer selected it as successor on
2026-11-06. Plans64/65 are source history awaiting separate cleanup; neither their continued
presence nor that cleanup changes this plan's authority, scope or premise. No past plan owns
a prerequisite. This series owns only remaining changes, missing consumer integration and
required outstanding acceptance. It does not repeat implemented scope as new work.

case and scientific purpose → compatible preparation and class-specific library execution →
original assessment → protected products → independent useful reading. Developer operations
have explicit selection, prerequisites, performing work, full original evidence and valid rerun.
Boundary formats describe those meanings; they do not become another scientific authority.

process-guidance changes. The preserved science, contracts and persistence worktrees contain
unfinished candidates, not an assembled baseline. FeedFlash changes, root-scoped result adapter
emission and selected-result consumer wiring still need integration or replacement and receiving
evidence. Preserve them until the corresponding implementation decides their disposition;
authoring this series neither merges nor deletes them.

**Interface-checked:** the review/source evidence characterizes current native declared/prepared
operations, completion scope, source-owned projections, protected readers, atomic witness capture,
granular preparation, numerical kernels and host evidence owners. Schema search, original fixture
inspection, generic reentrant settlement, unique surrogate retirement, IPC duplicate-key refusal,

schedule only their changed consumers, demonstrated gaps and remaining acceptance. Package labels
or differing integrated commit hashes cannot justify recreating these foundations.

and test-assessment1.2 with the repository binding. Blueprint §4–§24 and retained ADRs supply

candidate work until integrated or deliberately superseded. These instructions schedule later
execution; authoring does not resume paused product workloads.
