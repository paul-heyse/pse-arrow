## I-A1: selected structural cutoff and its actual obligation

**Select retained, granular Salsa preparation**, not deletion of Salsa and not a persisted Salsa database. The pure-function alternative avoids memo bookkeeping but repeats untouched parsed/type/occurrence products on each structural publication; a retained monolithic catalog alone still invokes `check_with` over the complete changed source. The mechanism control demonstrates that retained equal intermediate results can stop downstream work. Existing compiler/data-document queries and detached allocation owners supply integration seams without moving semantic authority or canonical effects into Salsa.

The selected compiler-owned lane receives an admitted parent and exact row/document delta. Inputs are immutable declaration fields keyed by semantic declaration/field identity, explicit ordered sibling/import/membership populations including empty/absent results, exact physical/scope/provider/interpretation context, and admitted document identities. Parse products own exact field bytes, grammar, field role/position and span attribution. Resolve/type/effective-member/checked-occurrence products depend on every value or namespace population consulted; selected root specialization consumes these products. Equality applies to complete immutable results, not a hash hint or normalized body alone. A source span/provenance change may preserve mathematical lowering while still changing its attribution product.

Checking remains whole-package *in meaning*: every newly published inventory must satisfy required duplicate, parent, inheritance, function/type-cycle, declaration-role, record/data, provenance and physical rules. Their evaluation is partitioned by affected lexical scope and graph component. Namespace edits invalidate all lookups whose positive/negative/ambiguity premises change. Graph edge edits recheck the affected old and new dependency components and their dependent components; deleting an edge cannot leave a cached cycle witness or dependent member closure. Existing graph validation supplies explicit diagnostics; no Salsa fixpoint cycle is used to admit invalid authored cycles. When a rule's dependency domain cannot be represented completely, its query conservatively depends on the enclosing inventory. This is an honest coarse remainder, not a claim that that phase already has cutoff.

One writer owns each live problem/lineage/context lane. Stage candidate inventory/delta and reserve its allocations first; apply its tracked input batch and evaluate candidate queries under exclusive lane ownership, then publish the admitted head only after all obligations succeed. No external query observes a partially updated batch. Failure restores the old logical inputs/head before releasing ownership; candidate-only inputs remain bounded/accounted or trigger generation rotation. This is an application-owned atomic head update, not a claim that Salsa setters are transactional or a requirement to full-check twice. Reads finish or cancel/drain before a write; no cloned database handle escapes. Completed products and historical revisions detach into existing charged immutable Arcs. Branch/historical requests use their detached admitted products or an independent bounded lane; selecting an old revision does not rewind the live head or block on a historical reader's lifetime. Idle lanes evict, byte/entry pressure rotates storage, and retained outputs continue holding allocations until their final borrower drains.

F07's compiler implementation cannot close from the toy memo control or the documentation correction. Acceptance requires a consumed structural edit in a real multi-definition package: affected occurrence/type products rerun; untouched siblings and downstream equal products do not; namespace add/remove/shadow/import, absent name, duplicates, cycles, record/data/physical ambiguity and A/B/A controls agree with a fresh complete checker. Cancellation, staged publish failure, lane pressure, two writers and historical detached readers retain exact source and drain semantics. The initial boundary remains P-A1/P-A2/P-A5 before migration, but choosing the structural design is no longer deferred behind those implementations. P-G0 owns governing amendments. The full checker stays the independent fresh oracle until each subsumed phase and every caller has migrated, then the duplicate production path is removed.

## I-A5: optional publication evaluated now; default retained

**Retain synchronous exact settlement once per engagement. Separately propose explicit optional reusable-product publication, without an automatic background queue.** Investigation need not wait for production engagement implementation: the source separates immutable mathematical products from root admission, and the target-shaped effects fixture makes the observable distinction clear. There is no measured case here for adding a scheduler/retry queue, extra result type authority or automatic durability omission.

The concrete separate proposal is an explicit preparation option `ReusablePublication::{Required,Explicit}`. `Required` remains the current default and returns only after all promised reusable-product effects settle. `Explicit` can return a mathematically admitted `PreparedUnpublished` owner and may offer an explicitly awaited `publish_reusable` operation producing `PreparedPersisted` or typed failed/uncertain outcome. Required durable result publication remains independent and mandatory under its existing policy; transient mathematical success never represents durable result success. Ephemeral use may choose Explicit and never call publication only after the operator approves that effects change.

Each publication gets one immutable operation identity and original expiry. It holds payload, full receipt, source protection, allocation/settlement owner and any native work until actual settlement/drain. New publication after protection expiry/release refuses; an already dispatched effect can acknowledge its exact original rooted result without creating another root or refreshing the clock. Cancellation detaches a pure waiter only when safe and cannot free dispatched owners before drain. Bound outstanding work by existing allocation/admission, with no detached queue that grows outside it. A new explicit publication after an old definite failure is a new admitted operation; it must not impersonate retry of an uncertain original effect.

This changes externally promised preparation effects beyond accepted RC03 and therefore remains **separately Proposed**, unselected. P-G0 owns presentation of the concrete effects choice to the operator; P-A4/P-A5 and P-B1 own prerequisite receipt/root/held-protection implementation.
