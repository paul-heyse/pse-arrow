## D1 — One execution policy and explicit study causality

Migrate direct/reduced/complete-block/causal solve, initialization, recycle defaults, presolve Auto, fitting derivative/Hessian choice, dynamics Auto and linear-profile defaults to B's governing selection/transition semantics. Preserve complete contextual assessment, missing evidence and explicit backend constraints. Each scientific builder supplies the original class/representation/derivative witnesses and result-use criterion; adapters/schedulers do not reinterpret them. Conformance and normal execution consume the same prepared semantics.

Freeze owned preparation and effective policy/settings/advice for the products actually consumed. Independent points share neutral preparation, while declared continuation edges carry original predecessor seed/branch/numerical state. Lane count/completion order never invents a chain. Prepare discrete structural variants lazily when selected instead of enumerating an enormous space at admission; each variant still has complete physical/provider/dependency identity and charged lifetime.

Preserve current continuous refill, readiness as a derived hint rechecked against authoritative dependencies/cancel/retry/claim, bounded maintenance across studies and original visible ordinal ordering. Durable owner recovery reconstructs frontier without rerunning completed science. E2 supplies claim/owner incarnation and settlement appropriate to the selected deployment; native process lanes are not automatically durable writers. A stalled early study must not block later eligible maintenance.

Seed search filters complete eligibility before cutoff. Decode and carry one admitted seed with exact header/completion/branch/warm payload/allocation through the authorized start and prediction. New acquisition requires fresh permission; corrupt/infrastructure failure is not absence. Promoted artifacts can be independent of producer history, but do not replace this initial seed-admission obligation. **Targeted acceptance:** explicit/Auto same semantic decisions across scientific consumers; pending evidence versus refusal; independent versus declared chains under reordered lanes; lazy structural study variants; more recent ineligible seeds do not hide older eligible; one owned seed reused through prediction/start; frontier recovery/refill and bounded finalization under skew; cancellation/late child completion; original aggregate clocks/work remain unchanged. E/G add actual durable/installed journeys.

## D2 — Recycle history and a qualified map

Record bounded per-tear raw G(x)−x and physical Err/Tol at actual map evaluation, including sample role, inner tolerance/start/branch and failure/unavailable state. Distinguish accepted outer states, accelerated step norm, trial values and finite-difference perturbations. KINSOL's normal last-evaluated output is the default unless an explicit ReturnNewest choice changes it; failed G evaluation retains last successful state separately. Fresh original residual assessment grants acceptance, not native step convergence alone. Preserve temporary fixes/overlays and restore authored specification on every exit.

I-D1 tests the mathematical premise of acceleration: same tear x under different inner warm/branch histories, lane assignment and noise. Freeze a branch/start/inner-accuracy context making G repeatable, or expose the limitation and choose an appropriate method. History-dependent inner solves are not a single-valued map merely because the outer callback signature is pure. Record noise floors and the valid window before interpreting contraction/stagnation estimates.

Then compare library-owned damped/delayed Anderson with declared bounded restarts and current fixed-point policy on revealing cases. Nonmonotone progress alone is not a restart law. Restart has finite work/attempt/deadline allowance, resets actual native acceleration history and preserves terminal vetoes. Opaque Broyden/DQ/JFNK or equation-oriented simultaneous successors need actual representation/preconditioner/permission; custom Wegstein remains conditional on an unmet product/reference request and complete library comparison. B owns successor permission, C native machinery, D the map and scientific acceptance.

**Targeted acceptance:** contractive, oscillating, nonmonotone accelerated, noisy/branch-sensitive and domain-leaving maps; truthful raw residual history despite dropped telemetry; failed last map point; truncation; strict cancellation with no restart; total cap preserved; unchanged authored specification. PS-08 history is mandatory even if current defaults are retained after investigation. Convergence superiority is not claimed without representative evidence.

## D3 — Independent block profiles, ready execution and coupled tears

Existing initialization already derives/assesses per-block routes; automatic PreparedBlocks shares a backend/profile. Extend the same governing choice to independently configurable admitted block profiles using current structural products. Preserve numerical incidence, execution/validity/provider edges and optimization coupling; structural nonsingularity is not numerical rank or domain validity at new upstream values.

Only actually independent ready blocks can run together. Commit overlays in a defined order under declared branch/tolerance/determinism meaning, with finite resource/work budgets. Downstream blocks bind freshly committed predecessor values; no partial failed block leaks authored mutation. Preserve conditional schedule transactionality and blocks_step's fresh complete original evaluation. Polishing is a permitted candidate only when needed, not an unconditional second solve that hides block failure.

Tear/order formulation keeps SCC-local rows but globally shared decision columns, costs, group constraints and whole-graph acyclicity. Mandatory-edge cycles/self-loops and time-limit incumbents have honest outcome meaning; independently validate the resulting DAG witness. Splitting the optimization by SCC is invalid when choices/costs couple components. Shared structure serves execution only at its complete premise lifetime; native factorizations remain library-owned.

**Targeted acceptance:** mixed affine/scalar/dense/nonlinear blocks with independent profiles; predecessor/validity edges forbid false parallelism; value singularity after upstream update; rollback and original assembled refusal; coupled multi-SCC group/cost optimum/incumbent witness; ready wavefront capacity/cancel/drain. No promise that every large case uses every core; a coupled SCC may need a native inner solver.

## D4 — Dynamics continuation, events and demand

Use the same authored definitions with mode-specific owned layouts, consistent initialization, guards/envelopes and actual requested derivative/sensitivity order. Distinguish live solver continuation, event/discontinuity/new-IVP reinitialization, state-only process restart and arbitrary callback failure. Diffsol owns a different retained solver/state contract. Do not apply a generic IDA API to every backend or label a saved state resumable native history.

Retain compatible per-experiment integrator/checkpoint/worker ownership and exact parameter/event identity. Changed parameters/modes/branches invalidate the relevant numerical state. Preserve consistent starts, achieved horizon, sensitivity quality and typed incomplete trajectories. E3's sealed committed chunks may stream while live work remains bounded; published prefixes do not imply a complete horizon. Retain scientific event/jump and derivative checks even when output demand is compact.

Preserve implemented reverse sample cursors and their original ordering/endpoint/tolerance contracts. Shooting windows become parallel only under a genuine decomposition with full boundary/jump/branch/derivative dependencies and charged snapshots. Value-only trials avoid sensitivity integration; later First/Second upgrades refresh coherently and record achieved order. A numerical-method upgrade can change primal steps within the declared physical tolerance and still requires independent derivative/original controls. Eager First is a measured-demand policy candidate, not mandatory default.

**Targeted acceptance:** live pause/continue versus state restart and event; parameter change resets appropriate history; reverse/duplicate/end samples; partial horizon/prefix and cancellation; consistent initialization/refusal; requested/achieved derivative orders and jump sensitivities against independent references; shooting boundary failure and charge release. General event-sensitive scientific adequacy remains an explicit G2 scope, not inferred from endpoint residuals.

## D5 — Fitting, sensitivities and surrogate work

Jointly select fitting algorithm, derivative mode and actual experiment products through B. Preserve current point-cache/adjoint upgrade, exact Hessian versus Gauss–Newton, forward/adjoint sensitivity, covariance/profile and event-sensitive contracts. A value-only objective should not compute unused response/Jacobian/trajectory families. Retain compatible per-experiment workers/integrators with complete reset/parameter/branch/start premises; covariance rank/conditioning can withhold an answer honestly rather than synthesize certainty.

Independent experiments use admitted contexts and a defined reduction order; arbitrary floating accumulation/branch order is not interchangeable. Extend existing FitProblem::profiles' quiescent admitted threads×workers/stacks/resident accounting rather than introducing another profile scheduler. Profile chains retain their declared causal seeds. Parent-resident memory stays charged while compute is lent; construction queues and foreign teams are finite. C4 owns placement and F3 actual build/launch consequences.

Preserve EgorState with its actual native worker, compact Advance summary and explicit charged snapshots; normal advancement does not clone full samples/RNG/model history unnecessarily. Retain RNG/proposal/failure semantics and achieved-order shooting behavior across fits. Source relocation already reflected in runtime manifests is baseline; 38f owns remaining dependency/consumer verification, not another semantic surrogate implementation.

I-D2 identifies any remaining objective/gradient/preparation work mismatched to selected demand, actual repeatable experiment independence and necessary derivative/noise accuracy. Choose sequential retained contexts first where that is the complete fitting target; parallelism follows real independence and C4 resources. Do not assert adjoint always superior or that current event derivatives are universally qualified.

**Targeted acceptance:** Value/gradient/adjoint/Hessian upgrades at same point; changed parameter/event/start; independent objective/derivative reference; covariance refusal and profile branch; ordered sequential/parallel reductions; retained context versus fresh; surrogate proposal/RNG equivalence, bounded summaries/snapshots and failure/drain. Actual full fitting/dynamic journeys belong G2.

Its local 1e−5 perturbation and 1e−7 repeatability allowance establish only that declared smooth
window, not a global noise floor. Native controls cover contractive, oscillating, nonmonotone,

### I-D2 — Fitting demand and experiment ownership

Value demand omits unused steady response Jacobians and transient sensitivity integration;
same-point First/Second/statistical upgrades preserve the exact context, check physical
agreement and install the final candidate coherently. Rank/conditioning can withhold covariance.
Owner-affine workers retain compiled operations and allocations. Every parameter trial creates
fresh native IVP state; no multistep history crosses changed parameters/events/starts.

`experiment_workers` is an explicit positive width, default one, distinct from profile-chain
workers. Independent experiments reduce in declaration order. Standalone teams borrow compute
through the existing quiescent phase; nested profile teams consume their already admitted
combined envelope, with parent resident memory, complete native teams and stacks charged.
Profile owner threads enter the parent's Tokio/native/construction contexts before nested
workers start. Every launched actor joins before failure/cancellation releases its ownership.
The parallel control uses a barrier to establish real overlapping entry and independent
analytic objective/gradient references; it does not claim measured speedup.

Full live simulation retains explicitly requested sample sensitivities. Compact currently
streams physical values only and returns typed Unsupported for explicit sensitivity demand
before activity/attempt/native dispatch. Internal method Jacobians remain permitted. Compact
retains mandatory original checks, events, coverage, endpoint and demanded private diagnostic
samples; both its scalar-cell cap and task/comparator allocation follow actual retention.
Derivative streaming requires a later complete transport contract, not silent demand removal.

### I-D3 — Optional comparable-effort displacement

`EffortPolicy { target_iterations }` extends the existing StepControl and is absent by default.
Only nonzero actual Ipopt/KINSOL iteration counts from the same effective backend/profile can
adjust the next qualified displacement. Missing, zero or foreign evidence restores the declared
baseline. The factor is bounded by 0.5 and the permitted growth, then by min/max/remaining
displacement. Rejection/attempt/work/deadline allowances and original endpoint/connected-path/
branch checks are never reset. A native homotopy control compares completed original-qualified
endpoints with the baseline and confirms that selected effort changes displacement; it makes
no general convergence or runtime claim.

## Outcome

### Delivered scope

**Implemented / Tested:** D1–D5 and I-D1–I-D3 are complete within the explicit support and
targeted acceptance above. Lazy source constructors, actual selected seed admission, block
profiles/ready execution, frozen causal context/native restarts, bounded live output with
original science and recording settlement, demanded retained fitting workers/ordered teams
and optional effort displacement reach their Rust/Python consumers. Replaced eager-only
study assumptions, shared-only block assumptions, stateful inner starts, Full-only live
retention/admission, redundant fitting derivative work and terminal queue-slot dependence
were removed from the affected paths; supported explicit studies and Full reports remain.

**Implemented:** all worker changes are integrated on main; the three clean worktrees were
removed. Architecture revision 164 and proposed ADR-0186 own enduring contracts. This
completed companion remains for its active Plan38/38e–38g dependents and qualification readers.
Coordinator finding dispositions remain with Plan38; this does not close every shared F/RC
obligation. No selected implementation or investigative task remains in 38d.

### Mistakes corrected

Review exposed max-of-width underadmission instead of complete native-team sums, premature
Auto-curvature refusal, generic override validation rebuilding unrelated conditional products,
and Compact using Full allocation/cell demand. The replacements use actual effective profiles,
shared source facts and retention demand, with pressure/drain controls. Compact explicit
sensitivities initially had no delivered product; pre-dispatch typed refusal now prevents
silent demand loss. Early refusal/cancellation initially could lose the stream's terminal
result; the existing run watch now settles it without unbounded terminal backpressure.

Targeted controls also exposed a real missing Tokio context on nested profile threads; the
parent handle now spans each admitted owner thread. Initial runtime batches returned 13/16
and 18/20 passes and a native batch 4/5; invalid authored/Anderson fixture dimensions,
cancellation helper expectations and test callback/result shapes were corrected. The
pressure fixture now excludes reclaimable idle cache before claiming exact headroom; the
lazy-seed fixture now distinguishes Unresolved from Absent. Earlier compile failures and
warnings were repaired; the final canonical test build and Python correctness build are clean.
No scientific, work-budget, native-claim or recording acceptance condition was weakened.

### Deliberate limits and next owner

live output and effort adaptation remain explicit. No inner-map stateful continuation,
arbitrary study callback, portable native-history checkpoint or new storage topology was added.
