# Library capability overviews

Optional orientation documents introduce upstream capability families, advanced features and
general problem shapes. They are repository-agnostic; they do not prescribe this project's
architecture, assume installed versions or carry current priorities. Follow promising features
into Context7, primary documentation, upstream source/tests or the installed implementation.
Context7 is the first documentation lookup; an overview is not a prerequisite.

## Authoring and existing reference material

Use the [overview-authoring guide](authoring-guide.md) for new concise, comprehensive capability
overviews. Detailed authorship remains separate work; this scaffold supplies no library claims.
Existing [capability maps](../capability-maps/README.md) and their retained evidence remain in
place. Absent coverage or an empty search does not establish absence of a capability.

## Active and inactive library skills

[native-solver-libraries](../../.codex/skills/native-solver-libraries/SKILL.md) remains an active
local exception, selected and synchronized through the existing skill manager.
The other [central library-skill references](../../.codex/skills/README.md#inactive-central-library-skill-references)
are inactive historical context. Their sources remain central, but they are no longer selected,
discovered or required here. Existing plans may name them; references can improve when those plans
are deliberately revisited, without a plan migration for this transition.
