# Engineering inquiries

These optional examples support investigation; the calling skill owns its lens, conclusions
and publication. Start with the smallest source-only question and expand a particular unknown.
Use actual command help/schema for operands and pass returned `address` strings unchanged.
The encoded address preserves native path bytes and integer guards through ordinary JSON clients.
An available command is not a requirement to use it.

## Authority, enforcement and consumers

Start with the named contract section and its native owner. Find authored references and
declarations before preparing an analyzer:

```bash
pse search text 'force_validate' --literal --path crates/pse-host/src --context 1
pse inspect --source crates/pse-host/src/correctness.rs --head 30
pse search symbol QuantityRegistryBuilder --path crates/pse-quantity/src
```

A mention nominates a place to inspect. It does not establish ownership, enforcement or
implementation. Use a guarded result's association view to follow declared ownership,
generated origins, explicit citations and canonical plan/package records when needed.
For example, `pse inspect --result ADDRESS --view associations --budget 8` reads the selected
source and available canonical document evidence. Add `--semantic` only for Rustdoc symbol
resolution through an explicitly prepared world; an absent document interpreter remains
unavailable rather than being prepared by inspection.
Use native relationships only when identity, aliases or shared consumers matter. Inspect
coverage and an original witness before drawing absence conclusions.

Design audits use this evidence to investigate causes. Design reviews compare complete
alternatives. Functional reviews may explore a capability without an existing caller.
Those are different judgments, even when they use the same source facts.

## Local wrapper and library capability

Start with an acquired artifact or source wrapper; acquisition and native preparation are
explicit. A structured signature query and original declaration/docs can answer an API
question without a compiler experiment:

```bash
pse search api PATTERN --artifact ARTIFACT --input "for<'a> fn(&'a u8) -> &'a u8"
pse inspect api PACKAGE --docs --declaration
```

Command help supplies the actual selected package/artifact grammar. Prefer a
returned guarded reference to reconstructing an artifact-local item ID.
Shape, declared adjacency, destination availability and an actual call's obligations remain
different evidence. Follow the particular unknown into native context or an explicit authored
probe only when it changes the decision. A missing defining artifact is unavailable evidence.

Codebase leverage inquiry explains the responsibility first; library assessment examines
capabilities and conditions; opportunity review compares complete options. Keep those lenses.

## Proposed change and evidence footprint

Inspect Git/source changes and retain before/after source and artifact addresses. Historical
bytes do not carry today's semantic world. Compare source/API observations independently;
request semantic comparison only with two explicitly prepared original worlds. Retained Cargo
metadata and admitted units can explain context differences without running Cargo again.

`pse inspect comparison --before-result BEFORE --after-result AFTER --view source` compares
written declarations and bodies. Select `api` for original acquired API records. A `semantic`
comparison additionally requires explicit `--before-checkout` and `--after-checkout` owners
and two original prepared-world references. `pse schema inspect comparison request` describes
the typed request form; `context` compares separately addressed retained metadata/unit premises.
Unavailable sides and ambiguous correspondence retain their original diagnostics.

Follow a relevant association into its original contract/package record. The record's date,
state and connection basis matter: a rejected alternative is not authority. Use the existing
test-selection owner to nominate current checks, preserving its conservative scope.

Plan preparation/creation uses this footprint to identify producer, consumer, generator and
validation work. Execution checks readiness; plan improvement considers the remaining combined
change and migration burden. None of these operations authorizes unrelated work.

## Original failure, setup and revealing checks

```bash
pse inspect tests INVOCATION --failures
pse inspect diagnostic INVOCATION
pse inspect invocation INVOCATION
```

Follow a frozen row/failure address to relevance inspection. Original setup, test outcome,
fixture declaration and actual settlement are separate. Inspect an assertion's guarded
operands and initializer/call references; operand position does not identify an expected value.
Use `pse inspect --source crates/pse-quantity/src/registry.rs --view relevance --budget 8`
for an independently useful written view, or `pse inspect --result ADDRESS --view relevance`
for a returned original source, diagnostic or frozen-test address. Optional `--semantic`
adds current native tests and calls only for a separately authenticated source witness.
Shared calculation or comparator calls can reveal a question about independence without
settling it. Custom/shadowed macros may remain opaque.

Current source correspondence is not proof of the historical assertion. A current guarded
source can feed `inspect test-selection --from-result REF`; original evidence cannot silently
become current selection authority. Inspection never lists fresh tests or executes them.

## Discovery, correction and stopping

Use `commands FAMILY`, then `help COMMAND` and `schema` for selected detail. `search --explain`
shows the effective validated request and origins without providers. Top-level `--fields`
selects literal payload fields; it is not a nested projection language. Correct invalid input
using typed choices, paths/rules and preserved source diagnostics. Redacted or truncated
validation evidence cannot supply omitted selectors or establish native fact truth.

Stop when the bounded evidence answers the question. Expand a guarded source, original
artifact or particular unknown when necessary; do not substitute a larger page for coverage.
Partial streams, cancellation requests and actual CPU settlement retain distinct meanings.
