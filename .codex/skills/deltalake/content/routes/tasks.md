# Task routes

Reviewed depth is selective. Search the full operation index for unreviewed tasks.

| Task vocabulary | Decision brief | Input → output |
|---|---|---|
| Unity catalog; AWS Glue catalog; resolve table name; catalog provider; table discovery | [Resolve table names separately from storage and provider freshness](../capabilities/delta.catalog.md) | catalog/schema/table identity, catalog client options → table storage location, DataFusion catalog/provider |
| change data feed; CDC incremental; CDF resume checkpoint; starting ending version; update preimage; residual filter | [Read change data with explicit bounds, images and residual filtering](../capabilities/delta.cdf.md) | loaded table, starting version or timestamp, optional ending bound → Arc<dyn ExecutionPlan>, DeltaCdfTableProvider, change rows and metadata columns |
| optimistic conflict; retry commit; post commit error; durable write failed; transaction recovery; max retries | [Reason about optimistic commits and errors after publication](../capabilities/delta.commit.md) | actions, snapshot/read set, CommitProperties, execution hooks → committed version, updated snapshot, post-commit result |
| update rows; delete predicate; no op version; DML metrics | [Update or delete through built-in Delta operations](../capabilities/delta.dml.md) | DeltaTable, predicate, column expressions → (DeltaTable, UpdateMetrics), (DeltaTable, DeleteMetrics) |
| protocol support; reader writer features; timestamp nanos; feature flag; identity columns; column mapping support | [Separate feature vocabulary, protocol admission and operation support](../capabilities/delta.features.md) | table protocol, Cargo feature profile, operation → admission result, operation-specific decision |
| restore version; time travel; checkpoint log; history metadata; recover historical | [Choose time travel, restore, checkpoints or log maintenance](../capabilities/delta.history.md) | table version/history, restore target, loaded table → historical snapshot, new restored version, checkpoint artifacts |
| Delta kernel engine; low level scan; selection vector; Arrow engine data; kernel fork; custom engine | [Use kernel snapshots, scans and engine interfaces at the correct layer](../capabilities/delta.kernel.md) | kernel schema/snapshot, Engine, EngineData → scan metadata, filtered engine data, engine I/O results |
| upsert merge; duplicate source keys; null keys; matched update; by source delete; merge aliases | [Merge with explicit key, null, clause and duplicate semantics](../capabilities/delta.merge.md) | DataFrame source, join predicate, ordered clauses → (DeltaTable, MergeMetrics) |
| open table; time travel; load metadata; historical version; unloaded handle | [Open, load and select a table version](../capabilities/delta.open.md) | table URL, storage options, version or timestamp → DeltaTable, loaded snapshot |
| compact small files; z order cluster; optimize metrics; no op optimize | [Compact or Z-order while preserving logical data](../capabilities/delta.optimize.md) | DeltaTable, partition selection, target size, OptimizeType → (DeltaTable, Metrics), rewritten files |
| read delta rows; scan projection; raw parquet; deletion vectors; column mapping; provider freshness; dictionary partition | [Choose a Delta-aware scan or table provider](../capabilities/delta.read.md) | DeltaTable snapshot, projection, DataFusion filters → Arc<dyn TableProvider>, SendableRecordBatchStream, Arrow RecordBatch |
| replace where; overwrite partition; predicate overwrite; replace subset | [Choose full overwrite, predicate replacement or merge](../capabilities/delta.replace.md) | replacement batches, predicate Expr or SQL, loaded table → new DeltaTable version, preserved rows outside predicate |
| idempotent ingestion; replay batch; transaction application version; deduplicate append; exactly once | [Use transaction markers without assuming replay suppression](../capabilities/delta.replay.md) | application ID and version, CommitProperties, snapshot transaction state → txn action, transaction_version lookup |
| vacuum cleanup; dry run; full lite orphan files; retention historical reads; keep versions | [Preview and execute vacuum with explicit historical-read consequences](../capabilities/delta.retention.md) | DeltaTable, retention interval, VacuumMode, kept versions → (DeltaTable, VacuumMetrics), deleted or candidate file paths |
| schema evolution; merge schema; safe cast null; timestamp timezone; unsigned decimal nested; column mapping metadata | [Preserve schema meaning across Arrow, Delta and schema evolution](../capabilities/delta.schema.md) | Arrow Schema, kernel StructType, nullable/nested arrays, SchemaMode → normalized Delta schema, Arrow Schema, evolved table metadata |
| custom session; UDF lost; planner MetricObserver; runtime memory spill; session fallback | [Preserve session capabilities and configure Delta planning](../capabilities/delta.session.md) | SessionState, Arc<dyn Session>, RuntimeEnv, UDF registry → DeltaSessionContext, resolved operation session |
| S3 Azure GCS HDFS LakeFS OpenDAL mount; object store registration; credentials; storage backend; atomic commit | [Choose object storage and log publication adapters](../capabilities/delta.storage.md) | URL scheme, StorageOptions, ObjectStore, LogStore → configured table storage, backend publication behavior |
| append data; write plan; stream writer; flush commit; save mode ignore; target file size | [Write batches or a logical plan; distinguish staging from publication](../capabilities/delta.write.md) | Vec<RecordBatch>, LogicalPlan, RecordBatchWriter → DeltaTable, Add actions, committed version |
