# Alignment notes: what the surveys require of the model

Working list for the alignment step (plan packet TK2). Each item is a fact a survey established
from pinned bytes and the change, if any, it requires of the declaration in `model/` and
`forms/`. An item is removed when the declaration holds it and a fixture proves it. This page is
a worklist, not a contract.

## Requires a model or meta-model change

| # | Evidence | Survey | Required change |
|---|---|---|---|
| 1 | Margules pair parameters transform as (h0, h1) → (h0 + h1, −h1) when the pair is swapped | cantera | a `linear` transposition rule: a declared matrix over named slots; `symmetric`, `parity` and `reciprocal` stay as the common special cases |
| 2 | One curve form serves bubble and dew pressure of pseudo-pure fluids; one equation serves as an alpha function under several equations of state | coolprop | decide how one equation is used for several observables: a form implementing more than one contract, or the observable chosen at the slot group; until then only the single-observable case is declared |
| 3 | Sigma profiles are three blocks (non-hydrogen-bonding, OH, other) on one grid, distinguished only by position; a pore-size kernel is a table on two axes | cosmosac_nist, pygaps | `tabulated_function` needs several named series on one grid and more than one axis |
| 4 | 94 % of ISODB isotherms do not say whether loading is excess or absolute; loading units come in 83 spellings and only per-mass fits `Loading`; temperature has no unit | isodb | an adsorption kind `not_stated`; loading bases per volume, per surface area and per unit cell; the mapping must hold rows whose unit cannot be parsed instead of guessing |
| 5 | A source can hold two rows for the same pair under the same selector with different values (ThermoPack `kij` for two pairs, 25 UNIFAC rows; teqp three duplicated pairs; Cantera 69 species names with conflicting thermo blocks across files) | thermopack, teqp, cantera | `parameter_set` identity needs a discriminator for repeated assertions within one parameterisation (an occurrence key from the source position), and the source's own rule for which one wins is a `selection_policy` fact, not a reason to drop the other |
| 6 | The same published set held by several carriers in different arrangements: AGA8 stores pre-combined GERG-2008 values and reverses one pair; teqp and CoolProp hold the published form | aga8, teqp, coolprop | `equivalence_assessment` must be able to name the transformation under which two records agree (a `derivation` of kind `conversion`), not only exact, within rounding and conflicting |
| 7 | Default choice among competing tables is behaviour: dictionary insertion order (chemicals), a tag list with an in-band `DEFAULT` marker (ThermoPack), ordered libraries and `rank` (RMG), first table only (thermo) | chemicals, thermopack, thermo | `selection_policy` must be scoped (per observable, per slot group) and must be recordable as a source-asserted fact with its locator, including where the documented order and the code differ |
| 8 | A parameterless association site means "induced association only" (FeOS); a pair record may carry no parameters | feos | say how a site without parameters and an empty pair record are represented: a declared value state, not an absent row |
| 9 | Verification values ship with the formulation (AGA8 16-digit test values, IAPWS check tables) | aga8 | a `dataset` of kind `verification` needs a link to the model assembly and parameterisation it verifies |
| 10 | An interaction parameter's meaning depends on a composition basis the source leaves to the caller (Flory–Huggins chi in volume, mass or segment fractions; a relative size against an undeclared reference volume) | flory, polykin | a parameterisation or slot group must be able to state the composition basis and the reference volume its values assume; `pseudo_component` of kind `abstract_component` needs a size |
| 11 | Liquid-state integral-equation inputs are site types with number densities and pair tables; there is no molecule or species record | pyprism | site number density as a composition basis; site types as abstract entities |
| 12 | In a hierarchical group scheme the order of sibling nodes decides matching (first matching child), and a node with no data is an instruction to the estimator, not missing data: group, radical and pair trees climb to the nearest ancestor with data, ring and polycyclic trees average the children | rmg_database | `group` needs a sibling position; `group_scheme` needs the rule for a data-less node (nearest ancestor, average of children), which the estimation derivation also cites |
| 13 | Fitted group values come with full covariance matrices (316 × 316 and 188 × 188); an estimate's lineage exists only as free text that the library parses back | rmg_database, rmg_py | a fit holds its covariance as typed standard uncertainties of its free parameters (`fit_free_parameter.standard_uncertainty`, in the unit of the parameter's slot) and the correlations between pairs of them (`fit_correlation`); an estimation `derivation` lists the group sets it combined as inputs instead of a comment string |
| 14 | The order of constituents in an interaction fixes the sign of odd-order binary terms and which constituent a ternary order index selects; the TDB reader sorts alphabetically and discards file order, the ChemSage readers keep file order; the order integer means three different things depending on how many constituents interact | pycalphad, thermochimica | `constituent_array` members need a position within their site class, and the array's canonical key a declared ordering convention; the compound-energy contribution forms are separate per number of interacting constituents, so the order index has one meaning per form |
| 15 | Piece boundaries are read differently: half-open and zero outside (pycalphad reader), extrapolated by default (pycalphad model), upper-inclusive and extrapolated upward (Thermochimica) | pycalphad, thermochimica | piece intervals stay half-open as stored; what a consumer does outside them is an extrapolation policy of the consumer, recorded with a qualification case, never a property of the data |
| 16 | A substance's standard-state model is assembled per substance from up to three parts (a general equation of state, a temperature correction, a pressure correction), and which part a listed method fills is decided by the method code in the reader, not by the record; a solute model additionally needs a solvent density and permittivity model | thermofun, reaktoro | a standard-state `model_assembly` chosen per species form (not one per parameterisation), with sub-form slots for the three parts and for the solvent model; the code-to-slot table is mapping knowledge declared in `mapping.toml` |
| 17 | Sources conserve things that are not elements, charge or site totals: isotopes and isotopologues (PHREEQC `[18O]`, ThermoHub isotope mass and abundance, ThermoPack and Cantera deuterium), the alkalinity pseudo-element (PHREEQC), a decoupled element inventory and ligand or moiety placeholders (GEMS `Nit`, `LIGAND`, `OTHER_EC`); `element.atomic_number` is unique, so an isotope cannot be an element | phreeqc, thermohub, gems3k, thermopack, cantera | an isotope refinement of `conserved_quantity` (symbol, mass number, atomic mass, parent element) with a verify invariant tying it to its element's balance; `conserved_kind` members `isotope`, `alkalinity`, `decoupled_inventory` and `moiety` |
| 18 | A rate constant's unit follows its reaction: concentration^(1−n)/time for forward order n, one more concentration power for a low-pressure limit or a third body, per area for surface participants and per volume for bulk ones; RMG writes A in six spellings accordingly | cantera, rmg_database | a slot (and a contract output) whose dimension is derived from the subject reaction's order and each participant's phase dimension, checked per set; storage stays coherent SI, so no second column is needed |
| 19 | A validity bound stated as an offset from another value of the same compound (Tb − 50 K to Tc − 100 K) with neither value in the file | chemicals | a `region_clause` bound expressed relative to a named observable of the same subject, stored as stated and resolved only when that observable is selected |
| 20 | Temperature-scale difference tables relate ITS-90 to IPTS-68, IPTS-48, the 1976 provisional low-temperature scale and ITS-27 | chemicals | `temperature_scale` members `its_76` (EPT-76) and `its_27` |
| 21 | Group schemes repeat a subgroup name under different codes (CHO twice in both Dortmund workbooks; CH3S, CH2S and CHS in original UNIFAC); heterosegmented SAFT needs the bonds between the groups of one molecule (Clapeyron intragroups, FeOS segment bonds); NeqSim lists TEG twice in one assignment table, first match wins | phasepy, clapeyron, feos, neqsim | a group identified by (scheme, the scheme's own code) with the label an attribute; a `group_bond_count` relation keyed by (assignment, group, group), symmetric with the diagonal allowed; `occurrence` in `group_assignment` identity, as in `parameter_set` |
| 22 | A reference state can fix nonzero values at a named state: the IIR datum (h = 200 kJ/kg and s = 1 kJ/(kg·K) for saturated liquid at 0 °C), Clapeyron's stated H0 and S0; IAPWS-95 zeroes internal energy, not enthalpy, at the triple-point liquid | clapeyron, coolprop, iapws | an `energy_reference` that states the datum quantity (enthalpy or internal energy), optional stated enthalpy and entropy values with their amount basis, and the aggregation of the state |
| 23 | The COSMO-SAC dispersion term reads a dispersion class per molecule (NHB, HB-ACCEPTOR, HB-DONOR-ACCEPTOR, COOH, H2O) | cosmosac_nist, sigma_profiles_pyscf | an enumeration for the class, read by the COSMO-SAC-dsp form's pure slot group |
| 24 | Evidence from sublattice phases reports site fractions and configurations per sublattice; `dataset_column` names a component and a `dataset_phase`, and `dataset_phase` is not tied to a `phase_definition` | espei, espei_datasets | an optional `site_class` qualifier on `dataset_column`, and a `dataset_phase` that may name the `phase_definition` it reports on |
| 25 | An ordered phase names its disordered partner (TDB `DISORDERED_PART`, ESPEI aliases such as BCC_B2 of BCC_A2) and may switch the partition off (`NEVER_DISORDER`), which changes the equation | pycalphad, espei, espei_datasets | a relation pairing two `phase_definition`s, keyed by (chemical system, ordered, disordered), with the never-disorder switch as a column |
| 26 | Formulations state their accuracy per region of the state space (IAPWS-95 percentages per (T, p) region; IF97 consistency tolerances of 25 mK and 0.2 kJ/kg with rms and maximum differences); a rate rule states a normal distribution of ln k at a reference temperature | iapws, rmg_database | an `accuracy_statement` about a record's output observable over a validity region or at a stated condition, with an uncertainty kind, a statistic (stated bound, maximum, rms, bias, variance) and an absolute or relative magnitude |
| 27 | Sources give magnitudes without saying what they are (ThermoFun `errors`, RMG uncertainty tuples) and multiplicative uncertainty factors (RMG) | thermofun, rmg_database | `uncertainty_kind` members `unspecified` (a magnitude whose meaning is not stated) and `multiplicative_factor` (with a facet saying the magnitude is a dimensionless factor) |
| 28 | A library mixes CODATA editions: k_B from 2014, R from 2018, N_A derived as their quotient | kineticgas | `boltzmann_constant` and `avogadro_constant` on `convention_set`, read by forms the way `convention.gas_constant` is |
| 29 | Computed parameters name a level of theory (method, basis set, auxiliary basis, solvent model, software release; composites of a frequency and an energy level) | rmg_py | a `level_of_theory` kind that derivations, fits and parameterisations reference, in place of free text in `derivation.method` |
| 30 | A measured sample has several purity statements (basis, value, digits, analytical method), a stepwise purification history, a source that is not a supplier (SRM, isolated from a natural product) and a description status | thermoml_schema | a `sample` with `source` and `status` attributes, and per-sample relations of purity statements and purification steps |
| 31 | A dataset component can be a buffer, an inert or a cofactor; a compound can stand for an equilibrium mixture of species; a multicomponent substance can be an alloy, clathrate, complex, crystal or solution | thermoml_schema | `component_function` members `buffer`, `inert` and `cofactor`; a speciation state on `dataset_component`; a multicomponent kind on `defined_mixture` |
| 32 | Biochemical data are transformed (apparent) quantities at a stated pH, ionic strength and pMg | thermoml_schema | a `reference_relation` member for transformed quantities, and the conditions that define the transformed standard state |
| 33 | ThermoML states no standard pressure for any standard state and no scale for its infinite-dilution solute state, no frame for binary diffusion; its Joule–Thomson coefficient is isenthalpic; enthalpies of solution and dilution are per mole of solute | thermoml_schema | `not_stated` in `standard_state_kind` and `pressure_rule` with the infinite-dilution check accepting an unstated scale; `diffusion_frame.not_stated`; `path.isenthalpic`; an `amount_basis` per mole of solute |
| 34 | Quantities with no declared type: quadrupole moment (FeOS, ThermoPack), polarizability volume (IAPWS G5-01), electric potential (RMG charge-transfer rates), wavenumber and moment of inertia (RMG statistical mechanics), a surface excess that can be negative (2,549 ISODB points), kinematic viscosity, thermal diffusivity and fluidity (ThermoML) | feos, thermopack, iapws, rmg_database, rmg_py, isodb, thermoml_schema | quantity types for each; the surface excess on a difference scale, so `Loading` stays non-negative |
| 35 | Sources state defaults per slot: NRTL alpha 0.3, an absent temperature coefficient read as zero (`fillna(0)`), a volume translation of zero, an absent Troe T2 or SRI D and E | thermo, phasepy, feos, aga8, cantera | a typed default per (selection policy, slot) with a value state and a value in the slot's unit, in place of the policy's free-text `rule` |
| 36 | Citations point into a work: DECHEMA page references in ChemSep IPD comments | thermo | a locator (page, table, equation) on `attribution` |

## Held by the current declaration; the mapping must record the loss or assumption

| Evidence | Survey | How it is held |
|---|---|---|
| The equation a coefficient table belongs to is fixed only by a variable name or docstring; units are unstated or inconsistent across tables; one documented formula differs from the code | chemicals, thermo, clapeyron | a slot belongs to a form, so the mapping names the form per table; units are mapping assumptions recorded as loss; documentation-against-code differences are survey `[[discrepancy]]` records and the mapping follows what the code evaluates, saying so |
| The same parameter name has different meaning and unit in different tables (`bondvol`, `eps`, `kmat`) | clapeyron, thermopack, teqp | slots are form-local; nothing is mapped by name |
| A missing pair and a stored zero (or one) cannot be told apart | coolprop, thermo, aga8 | a stored value is mapped as `known`; the mapping rule records that the source cannot distinguish the two; a pair the source does not list produces no set |
| Computed values stored beside authored ones without a derivation record (states, ancillaries, generated estimation tables) | coolprop, chemicals | origin role `computed` or `estimated` with a `derivation` whose software or version is absent where the source does not record it |
| Enthalpy datum, temperature scale and gas constant are not stated | cantera, nasa_cea | `not_stated` members of the convention enums; a datum established numerically by the survey is a mapping assumption |
| Charge carried as a pseudo-element | cantera, nasa_cea | `composition` over `conserved_quantity` with the `charge` entity; the mapping converts the sign convention |
| One source row couples parameters of two forms (reducing parameters and the departure scale) | coolprop | the mapping emits two parameter sets from one import record |
| Identity is not a clean key: several entries share a CAS or InChIKey (ortho, para and normal hydrogen; site-scheme variants of water; conformers with different geometries) | thermopack, feos, sigma_profiles_pyscf | source entities stay distinct; spin isomers need curated decisions; site-scheme variants are one species under different parameterisations; conformer-level descriptors attach to the source entity's own record |
| A profile set is valid only with the model constants it was generated for | cosmosac_nist, sigma_profiles_pyscf | `dependency` between the profile parameterisation and the constants parameterisation |
| Fit provenance is not recoverable from the fitted database: only the best point is written, under generated symbol names with no link to datasets, and no covariance is kept | espei | a `fit` records what the source records; the missing links are `not stated`, not reconstructed |
| One wide component row feeds many incompatible models, and which model reads which column is decided by the consuming class; template rows carry placeholder values copied from water or methane, and a sentinel (an interaction value of one for ion pairs) stands for absence; most columns have no unit, range or citation | neqsim | the mapping splits one row into one parameter set per consuming form, declared per column group; placeholder and sentinel values are declared absent in `mapping.toml` with the evidence for each, and a row that is wholly template is `out_of_scope`, never data |
| Every equilibrium constant is relative to the basis its reaction is written on; the same species has different numbers under different master species, and one database ships two redox-basis variants | phreeqc | a `reaction` is its stoichiometry as written, so constants on different bases are constants of different reactions; nothing is re-based at import |
| The activity model is chosen by which keyword block a database contains, and defaults apply when a species has no ion-size parameters; site amounts and the electrostatic model are in the problem input, not in the database | phreeqc | the mapping declares the model assembly per database and records the source's block-presence rule as a selection fact; problem-input state is outside the knowledge base |
| Interaction rows are keyed by a sorted set of species names, so a repeated species loses its multiplicity; a later definition of a species or phase replaces an earlier one silently | phreeqc | subjects are role tuples, so the mapping must restore the multiplicity from the parameter kind; replaced definitions are both imported, distinguished by occurrence (item 5), with the source's last-wins rule recorded |
| What a program evaluates differs from its data file (CEA replaces stated temperature ranges when compiling its library) | nasa_cea | the file is what is imported; the runtime behaviour is a survey `[[discrepancy]]` and matters for qualification against the program |
