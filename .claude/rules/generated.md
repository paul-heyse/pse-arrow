# This file is output, not source

**Fix the generator, then run `just codegen`.** Editing here produces a change that the
next regeneration silently reverts, and a red `just codegen-check` in the meantime.

| Output | Generator |
|---|---|
| `crates/*/src/generated/` | `crates/pse-schema` (`cargo xtask codegen --only relations`) |
| `python/pse/contracts/` | `crates/pse-schema` (`--only python`); `GENERATED.sha256` is part of the output |
| `docs/generated/` | `crates/pse-schema` (`--only docs`) |
| `crates/pse-ipopt-sys/src/bindings.rs` | bindgen over `IpStdCInterface.h`, run inside the solver container (`--only bindgen`) |

Every generated Rust file carries `// @generated by pse-schema <fingerprint>`,
`#![rustfmt::skip]` and a blanket `#![allow(..., reason = "generated")]`. Generated docs
carry `<!-- @generated by pse-schema; do not edit -->`. If a file you are editing has one
of those markers, stop.

`just codegen-check` is `git diff --exit-code` plus an untracked-file check over these
four paths, and it is a required CI job. Generated sources are committed deliberately
(ADR-0031) so that a checkout builds without a code generator run and so that a
regeneration shows up as a reviewable diff — that only works if the committed output is
exactly what the generator emits.

A `PreToolUse` hook blocks writes here. There is no environment escape for it: unlike the
blueprint, there is no legitimate reason to hand-edit output.
